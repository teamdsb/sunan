# 苏南船舶管理系统操作手册

## 1. 文档说明

### 1.1 适用范围

本手册适用于当前版本的苏南船舶管理系统，覆盖企业微信 H5 中的以下板块：

- 我的
- 办事
- 采购管理
- 工作平台

系统以企业微信工作台为主要入口。用户可能直接从工作台应用、企业微信审批或消息链接进入某个业务页面，不要求先进入系统首页。

本手册依据 2026 年 7 月 12 日的需求文档、规格和实际代码编写。页面名称、字段和权限以用户所在组织及当前发布版本为准。

### 1.2 图片占位说明

文中的 `[图片内容：...]` 是后续截图位置。制作正式图文版时，应按占位说明截取真实页面，并用方框、箭头或序号标出需要点击的位置。截图前应隐藏手机号、证件号码、采购金额、审批意见等敏感信息。

### 1.3 当前版本边界

使用前请注意：

1. 本系统是企业微信 H5，不是微信小程序。
2. 页面中能看到的模块，不一定代表用户有新增、审批或治理权限。
3. “工作平台”已包含安全主数据、计划任务、待办日历、检查、统一问题和 CAPA 闭环；原有隐患/自查/检验/海事安检保留为可回链的历史来源。
4. 待办、日历和计划完成率使用同一任务数据源；正式业务以列表、详情、动作轨迹和审计记录为准。
5. 附件通过统一控件选择/上传，不要手工填写文件 ID；解除关联会二次确认并留痕。

## 2. 用户角色与权限

系统根据企业微信身份、部门和岗位映射角色。常见角色如下：

| 角色 | 主要权限 |
|---|---|
| 系统管理员 | 系统级配置、企业资料、制度、证照、模块治理和异常处理 |
| 总经办人员 | 总经办工作台、办事治理、部分企业资料维护 |
| 财务人员 | 财务工作台、采购审批、采购报表和财务业务 |
| 业务人员 | 业务工作台、船舶动态、作业流程和业务审批 |
| 船务人员 | 船务工作台、安全检查、航次、设备、燃油和船舶业务 |
| 后勤人员 | 后勤资产、仓库、办公、食堂、宿舍和车辆业务 |
| 船员 | 被授权的船舶作业、检查、考勤和个人相关记录 |
| 安全管理人员 | 安全主数据、计划、检查模板、问题/CAPA 和验证管理，范围受船舶/部门限制 |
| 全体员工 | 办事查询、被开放的工作台模块和本人可见记录 |

权限遵循以下原则：

- 无权访问的模块通常不会展示，或访问时显示无权限。
- 新增、编辑、发布、审批、关闭等按钮会按角色和记录状态变化。
- 同一页面在不同用户账号下可能显示不同操作。
- 船员默认只能读取本人、本船或本人参与的记录；措施责任人不能验证自己的措施。
- 发现权限过大、数据可见范围异常或按钮与岗位不符时，应暂停操作并联系管理员。

## 3. 登录、导航与退出

### 3.1 从企业微信进入

1. 打开企业微信。
2. 进入“工作台”。
3. 点击苏南船舶管理系统对应应用。
4. 系统自动完成静默认证。
5. 首次进入或认证失效时，按页面提示重新认证。

[图片内容：企业微信工作台中的苏南船舶管理系统入口，使用红框标出应用图标；下一张展示认证完成后的系统首页和四个一级板块。]

### 3.2 从深链进入

用户可能从以下位置直接进入具体记录：

- 企业微信审批通知
- 系统消息或提醒链接
- 工作台快捷入口
- 管理员发送的记录链接

进入后先核对页面标题、船舶、业务日期、状态和申请人，再执行操作。

### 3.3 页面导航

移动端底部导航用于切换主要板块；桌面或大屏模式使用侧边导航。详情页使用页面左上角返回按钮返回上一级。

[图片内容：移动端底部导航和桌面端侧边导航对照图，标注“我的、办事、采购管理、工作平台”的入口位置。]

### 3.4 重新认证

出现“登录已过期”“无有效身份”或企业微信身份变化时：

1. 点击“重新认证”。
2. 等待系统返回原页面。
3. 再次核对记录状态，避免重复提交。

如多次认证失败，应记录发生时间、页面地址和错误提示，交管理员处理。

## 4. 通用操作

### 4.1 列表查询

业务列表通常支持以下操作：

- 按关键字搜索
- 按状态筛选
- 按日期筛选
- 按分类或模块筛选
- 点击列表项进入详情
- 下拉或翻页加载更多记录

筛选后无结果时，应先清空筛选条件，再确认是否属于本人、本人部门或当前船舶的数据。

[图片内容：一个典型业务列表，标注搜索框、状态筛选、日期筛选、列表卡片、状态标签和进入详情的位置。]

### 4.2 新增与保存

1. 点击“新增”“新建”或“发起”。
2. 填写带星号的必填字段。
3. 核对船舶、日期、经办人和业务类型。
4. 点击“保存草稿”或“提交”。
5. 返回列表确认记录已生成且状态正确。

日期时间字段应按页面要求填写。工作平台的“发生时间”使用完整日期时间格式。

### 4.3 状态识别

不同模块的状态名称略有差异，常见含义如下：

| 状态 | 含义 | 建议操作 |
|---|---|---|
| 草稿 | 尚未正式提交 | 补全内容后提交 |
| 已提交/处理中 | 已进入业务流程 | 等待办理或按职责处理 |
| 待整改 | 检查发现问题 | 责任人完成整改并上传证据 |
| 待复核 | 流程步骤已完成，等待审核处理 | 按页面按钮提交审核、退回整改或关闭记录 |
| 审批中 | 已进入企业微信审批 | 在审批中心处理 |
| 已通过/已完成/已关闭 | 流程结束 | 查看记录或打印归档 |
| 已驳回/需返工 | 内容不符合要求 | 根据意见修改后重提 |
| 已停用 | 配置不再对普通用户开放 | 不再发起新业务 |

### 4.4 附件

系统附件可能来自：

- 本地文件上传
- 企业微信拍照或选择图片

上传后应确认文件名、数量和预览是否正确。不得上传与业务无关文件，敏感文件应遵守公司权限和保密要求。

[图片内容：文件上传控件，展示“选择文件、上传进度、已上传文件、预览/解除关联”区域和二次确认。]

### 4.5 审批

需要企业微信审批的记录会出现“发起审批”或“查看审批”入口。

1. 确认业务记录已保存。
2. 点击“发起企业微信审批”。
3. 在企业微信原生审批页核对审批人和表单内容。
4. 提交审批。
5. 返回系统查看镜像状态。

不要连续点击发起按钮。状态未及时同步时，先在企业微信审批中心确认是否已经生成审批单。

[图片内容：系统记录详情中的“发起企业微信审批”按钮，以及跳转后的企业微信审批页，标注审批人、业务摘要和提交按钮。]

### 4.6 打印与归档

采购单和采购报表支持生成 PDF 并打开下载。工作平台记录支持生成打印快照，但当前页面不一定自动展示下载地址。

打印前应确认：

- 记录状态是否允许归档
- 内容和附件是否齐全
- 打印版本是否为最新版本
- 文件中是否包含敏感信息

## 5. “我的”板块

### 5.1 首页

“我的”首页用于进入企业资料、企业制度、电子证照、证书提醒、船舶监控和设置。

操作步骤：

1. 进入“我的”。
2. 点击目标功能卡片。
3. 在列表或详情中继续操作。

注意：首页的任务、统计或预警展示可能包含演示数据，正式提醒以“证书提醒”列表为准。

[图片内容：“我的”首页全景，标注六个主要功能入口，并在任务展示区增加“以业务列表为准”的说明。]

### 5.2 企业资料

企业资料用于维护公司基本信息、联系方式和相关文件。

#### 查看

1. 进入“我的 > 企业资料”。
2. 点击企业条目。
3. 查看基本信息和附件。

#### 新增或编辑

1. 使用有管理权限的账号进入企业资料。
2. 点击“新增”或“编辑”。
3. 填写企业名称、统一社会信用代码、联系人、联系电话、地址等页面字段。
4. 上传相关文件。
5. 保存并返回详情核对。

[图片内容：企业资料列表、编辑表单和附件区三张图，分别标注进入详情、必填字段和保存按钮。]

### 5.3 企业制度

企业制度用于维护制度名称、版本、状态和制度文件。

#### 新建制度

1. 进入“我的 > 企业制度”。
2. 点击“新增制度”。
3. 填写名称、版本和说明。
4. 上传制度附件。
5. 保存。

#### 编辑与发布

1. 打开制度详情。
2. 点击“编辑”修改信息或附件。
3. 核对版本号。
4. 点击“发布”使制度进入有效状态。

发布前应完成内部审核。版本更新时不要覆盖历史语义，应按公司制度管理规则增加新版本。

[图片内容：制度列表中的版本和发布状态；制度详情中的附件、编辑和发布按钮。]

### 5.4 电子证照

电子证照用于登记公司或船舶相关证书、有效期、分组和附件。

#### 查询证照

1. 进入“我的 > 电子证照”。
2. 使用分组或关键字查找证照。
3. 点击证照查看详情、有效期和附件。

#### 新增或编辑证照

1. 使用有权限的账号点击新增入口。
2. 填写证照名称、编号、持有人或船舶、签发日期、到期日期和分组。
3. 上传证照扫描件。
4. 保存并核对。

当前版本如“新增证照”按钮没有响应，应停止重复点击，由管理员确认发布版本或通过后台维护。

[图片内容：证照分组列表和证照详情，标注证照编号、有效期、附件预览及编辑入口。]

### 5.5 证书提醒

证书提醒根据证照有效期生成到期预警。

#### 查看提醒

1. 进入“我的 > 证书提醒”。
2. 查看提醒看板。
3. 按状态或时间范围筛选。
4. 点击提醒进入详情。

#### 确认提醒

1. 打开提醒详情。
2. 核对关联证照和到期日期。
3. 完成线下续证或确认处理后，点击“确认”。
4. 填写必要说明。

#### 手动扫描

管理员可使用“立即扫描”重新检查即将到期或已经到期的证照。扫描是生成提醒，不等同于自动续证。

[图片内容：证书提醒看板，标注即将到期、已到期和已确认数量；提醒详情中标注关联证照、到期时间和确认按钮。]

### 5.6 船舶监控

船舶监控用于维护外部监控系统或船舶监控页面入口。

1. 进入“我的 > 船舶监控”。
2. 点击已有入口打开监控页面。
3. 管理员可新增、编辑或停用入口。
4. 外部系统打不开时，检查网络、登录状态和链接有效性。

该功能当前主要是外部入口管理，不等同于系统内置 AIS、CCTV 监控台账或值班交接。

[图片内容：船舶监控入口列表，标注入口名称、链接状态、打开和编辑按钮；另截取外部监控跳转结果。]

### 5.7 设置

设置用于维护个人偏好，例如提醒视图、证照分组方式和消息推送开关。

1. 进入“我的 > 设置”。
2. 调整开关或选项。
3. 等待页面提示保存成功。
4. 返回相关页面确认设置生效。

[图片内容：个人设置页，标注提醒视图、证照分组和推送开关，并展示保存成功提示。]

## 6. “办事”板块

### 6.1 浏览办事入口

1. 进入“办事”。
2. 按分类浏览服务入口。
3. 点击入口打开目标系统、网页或说明页面。

系统会记录入口打开行为，用于访问审计。

[图片内容：办事首页分类卡片和服务入口，标注分类切换、入口名称和打开位置。]

### 6.2 搜索

1. 点击搜索框。
2. 输入服务名称或关键字。
3. 从结果中选择目标入口。
4. 无结果时尝试简称或清空分类限制。

[图片内容：办事搜索页，展示关键字、搜索结果和无结果状态。]

### 6.3 办事治理

有治理权限的用户可维护服务入口。

#### 新增

1. 进入“办事 > 治理”。
2. 选择分类。
3. 点击“新增”。
4. 填写名称、描述、链接、图标或排序等字段。
5. 保存后发布。

#### 编辑、发布与停用

1. 打开目标入口。
2. 修改内容并保存。
3. 使用“发布”开放给用户。
4. 已失效入口使用“停用”，不要直接用错误链接替换。

#### 查看审计

治理页面可按分类查看入口的打开记录，用于了解访问时间和访问用户。

[图片内容：治理列表、新增编辑表单和审计记录三张图，标注发布状态、停用按钮和访问时间。]

## 7. “采购管理”板块

### 7.1 采购业务流程

采购主链路为：

`创建草稿 -> 提交 -> 部门审批 -> 终审 -> 完成/驳回 -> PDF 归档`

实际审批层级按采购类型、部门和金额配置确定。

### 7.2 新建采购单

1. 进入“采购管理”。
2. 点击“新建采购单”。
3. 选择采购类型或业务字典项。
4. 填写采购主题、申请部门、船舶、需求日期、用途和采购明细。
5. 添加附件。
6. 暂未确认时点击“保存草稿”。
7. 确认无误后点击“提交”。

采购明细应逐项核对名称、规格、数量、单位和备注。

[图片内容：采购新建页全景，使用序号标注采购类型、基本信息、采购明细、附件、保存草稿和提交按钮。]

### 7.3 查看与修改采购单

1. 在采购列表中按状态、日期或关键字筛选。
2. 点击采购单进入详情。
3. 草稿或被驳回状态可编辑。
4. 根据驳回意见修改后重新提交。

已进入审批的采购单不要通过重复新建来代替修改。

[图片内容：采购列表状态筛选和采购详情，标注申请信息、明细、附件、审批轨迹和可用操作。]

### 7.4 采购审批

1. 进入“采购管理 > 待审批”。
2. 打开采购单。
3. 核对申请人、部门、船舶、金额、明细和附件。
4. 填写审批意见。
5. 选择“通过”或“驳回”。

驳回意见应明确需要修改的字段或材料。终审通过前，应确认前置审批已经完成。

[图片内容：采购审批详情，标注审批层级、采购明细、附件预览、审批意见和通过/驳回按钮。]

### 7.5 采购单 PDF

1. 打开符合打印条件的采购单。
2. 点击“生成 PDF”或“打印”。
3. 等待系统生成文件。
4. 在新页面预览或下载。
5. 核对采购单号、审批结论和生成时间。

[图片内容：采购详情中的打印按钮和打开后的 PDF 预览页，标注下载位置。]

### 7.6 月报、年报与明细

1. 进入“采购管理 > 报表”。
2. 选择月报或年报。
3. 选择统计期间。
4. 查看汇总指标和采购明细。
5. 按需生成报表 PDF。

报表中的统计口径应与财务或管理制度保持一致。

[图片内容：采购报表页，标注期间选择、汇总指标、明细表和报表打印按钮。]

### 7.7 报表审批

1. 在报表详情发起报表审批申请。
2. 审批人进入“报表审批”。
3. 核对期间、汇总数据和明细。
4. 填写意见并通过或驳回。
5. 通过后生成归档版报表 PDF。

[图片内容：报表审批申请详情和审批页，标注统计期间、汇总数据、审批意见及 PDF 入口。]

### 7.8 采购字典

管理员可维护船务和后勤采购分类、名称、单位等字典。

1. 进入“采购管理 > 字典管理”。
2. 选择字典类型。
3. 新增或编辑字典项。
4. 调整启用状态。
5. 返回采购表单验证选项。

已经被历史采购单使用的字典项，宜停用而不是删除。

[图片内容：采购字典列表和编辑表单，标注分类、名称、单位、启用状态和保存按钮。]

## 8. “工作平台”板块

### 8.1 工作平台说明

工作平台按部门和业务域提供动态模块。当前主要模块如下：

| 业务域 | 主要模块 |
|---|---|
| 总经办 | 培训、会议、安全月、年度计划、安全隐患 |
| 财务 | 考勤、业务看板 |
| 业务 | 船舶签单、船舶动态、签到台、收货作业、围油栏作业、船舶垃圾、油污水、生活污水 |
| 船务 | 培训学时、演练、值守、靠离泊、船员会议、案例学习、船舶自查、船舶检验、有限空间、油污水、海事安检、考勤、设备维护、设备检验、海图更新、航次审批、燃油加注审批 |
| 后勤 | 仓库、办公、食堂、宿舍、车辆维修 |
| 作业工作组 | 中船作业流程、平陆运河作业流程 |

用户实际看到的模块由角色和配置决定。

[图片内容：工作平台首页，标注模块分组、模块卡片、记录数量、任务中心、安全主数据和检查/问题入口。]

### 8.2 打开模块

1. 进入“工作平台”。
2. 点击业务模块。
3. 查看模块说明、记录列表和新建入口。
4. 使用状态、日期或关键字筛选记录。

### 8.3 创建通用记录

大多数模块使用动态表单。

1. 点击“新建记录”。
2. 填写标题。
3. 填写业务摘要。
4. 选择或填写发生时间。
5. 按业务要求使用受控选择器选择船舶并填写动态字段。
6. 点击“提交”，创建业务记录。

当前动态字段主要支持文本、数字、日期和多行文本。人员多选、签名、定位和复杂检查项不是所有模块的通用能力。

这里的“提交”是创建记录的按钮。台账表单创建后仍为草稿，当前前端没有统一的二次流程提交按钮；作业流程和检查整改创建后可进入步骤推进。

[图片内容：工作平台通用新建表单，标注标题、摘要、发生时间、船舶选择器、动态字段和保存按钮。]

### 8.4 六类通用模板

#### 8.4.1 台账表单

适用于培训、会议、计划、动态、海图更新等记录。

当前通用操作：

1. 新建记录。
2. 填写台账字段。
3. 点击“提交”创建记录并查看详情。
4. 按模块条件发起企业微信审批。
5. 生成打印快照。

注意：台账类记录创建后没有统一的二次流程“提交”按钮。除培训等具有专用联动的模块外，应以详情中的实际按钮为准。

#### 8.4.2 作业流程

典型步骤为：

`班前准备 -> 作业前检查 -> 作业巡查 -> 作业完成`

工作组流程可能增加人员考勤步骤。

操作方法：

1. 创建作业记录。
2. 打开详情。
3. 点击“开始”进入第一步骤。
4. 完成当前步骤信息。
5. 点击“完成步骤”推进。
6. 全部步骤完成后确认关闭状态。

[图片内容：作业流程详情，标注步骤时间轴、当前步骤、开始、完成步骤和记录状态。]

#### 8.4.3 检查整改

典型步骤为：

`现场检查 -> 整改执行 -> 审核关闭`

操作方法：

1. 创建检查记录。
2. 开始现场检查。
3. 有问题时先在摘要或业务字段中补充问题说明，再点击“标记整改并推进”。
4. 整改责任人完成整改。
5. 全部步骤完成后点击“提交审核”。
6. 审核不通过时点击“退回整改”，通过后点击“关闭记录”。

需要法规/公司/船舶版本检查、多人签认、根因分析和纠正预防措施时，从“工作平台 > 检查/问题中心”进入专用链路；原通用记录作为历史来源只读查看。

[图片内容：检查整改详情，标注检查步骤、标记整改并推进、提交审核、退回整改和关闭记录按钮。]

#### 8.4.4 考勤统计

1. 进入考勤模块。
2. 选择时间范围。
3. 查看出勤汇总和明细。
4. 按需发起导出或对账任务。

当前“钦州范围”等范围判断主要依据业务文本，不是实时经纬度电子围栏。导出或对账提示排队后，如未产生下载文件，应联系管理员。

[图片内容：考勤统计页，标注日期范围、汇总指标、明细表、导出和对账按钮，并提示当前定位口径。]

#### 8.4.5 服务资产

适用于仓库、办公、食堂、宿舍、车辆维修等后勤记录。

1. 选择服务或资产类型。
2. 填写对象、日期、数量或情况说明。
3. 保存记录。
4. 按页面提供的审批或打印入口继续处理。

#### 8.4.6 企业微信审批

适用于航次、燃油加注等需要原生审批的业务。

1. 填写业务记录。
2. 保存。
3. 点击“发起企业微信审批”。
4. 在原生审批页提交。
5. 返回系统查看审批状态。
6. 审批异常时由管理员执行重试或对账。

### 8.5 培训

培训模块用于记录培训主题、对象、进度和完成情况。

1. 进入培训模块。
2. 新建培训记录。
3. 填写培训主题、时间、对象、讲师和内容。
4. 更新学习进度。
5. 进度达到完成条件后，系统准备企业微信审批。
6. 在审批页完成确认。

当前培训尚未覆盖参考安全管理平台的需求分析、年度计划、自动生成培训记录、考试题库、熟悉职责和开航前置校验全链路。

[图片内容：培训记录新建页、进度字段和完成后出现的企业微信审批入口。]

### 8.6 会议

1. 进入会议模块。
2. 新建会议记录。
3. 填写主题、时间、地点、主持人、参会范围和纪要。
4. 绑定会议附件。
5. 保存并查看详情。

[图片内容：会议表单和详情，标注会议基本信息、纪要、统一附件控件及打印入口。]

### 8.7 隐患、自查、检验与海事安检

这些模块当前共用检查整改流程。

1. 新建检查记录。
2. 填写检查主题、船舶、日期和发现。
3. 推进现场检查。
4. 有问题时补充问题说明并点击“标记整改并推进”。
5. 填写整改结果和证据。
6. 全部步骤完成后提交审核。
7. 审核通过后关闭；不通过则退回整改。

同一问题不要在多个模块重复创建。原有四类记录会映射或手工关联到统一问题，可从问题详情返回原记录。

[图片内容：隐患或船舶自查的完整三步状态截图，依次标注发现问题、整改结果和复核关闭。]

### 8.8 设备维护与设备检验

1. 进入设备维护或设备检验模块。
2. 新建记录。
3. 填写设备、船舶、维护或检验日期、内容和结果。
4. 按检查整改步骤处理异常。
5. 生成打印快照归档。

当前模块侧重单次记录，尚未形成设备模板、年度计划、月度计划、缺陷、修理、备件库存和执行统计的完整链路。

[图片内容：设备维护记录表单和整改详情，标注设备信息、维护内容、结果、异常整改和打印按钮。]

### 8.9 有限空间、油污水及其他船上作业

1. 选择对应作业模块。
2. 填写作业主题、船舶、时间、作业地点、负责人和安全说明。
3. 完成班前准备和作业前检查。
4. 作业中完成巡查记录。
5. 作业结束后完成最后步骤并关闭。

作业许可、气体检测、人员签名、现场照片等信息若页面没有专用字段，应按公司制度通过说明和附件补充，不能因系统字段有限而省略法定或制度要求。

2. 新建记录。

7. 返回系统确认审批结果。

2. 点击“生成打印快照”。
3. 等待成功提示。
4. 生成成功后使用页面下载链接打开 PDF；异步导出在任务详情查看进度、失败原因和重试入口。

## 9. 移动端现场使用

### 9.1 推荐操作方式

- 从企业微信工作台或消息深链直接进入任务。
- 现场网络不稳定时，先确认保存成功再离开页面。
- 上传大文件前检查网络。
- 避免在多个页面同时编辑同一记录。
- 审批完成后返回系统核对状态。

### 9.2 拍照、定位与签名

安全检查任务提供企业微信拍照、定位和 H5 手写签名。定位是否必填由任务/模板决定。

需要现场证据时：

1. 优先使用页面提供的上传或企业微信图片能力。
2. 图片应包含可识别的设备、地点或问题对象。
3. 不得用无关图片代替现场证据。
4. 页面没有定位或签名控件时，按本单位现行线下制度补充。

### 9.3 消息与待办

从“工作平台 > 任务中心”切换待办、我发起、我参与、已完成和逾期，并在列表/日历查看同一任务。企业微信任务消息会深链到任务详情，认证后返回原任务。

### 9.4 安全主链路

1. 计划负责人创建计划与计划项，设置周期、责任人、参与人和完成规则。
2. 启用后生成任务，责任人从待办、日历或消息深链进入。
3. 检查人按版本快照完成检查项、附件、定位和签名；多人门槛满足后才能汇总。
4. 不符合结果去重转为问题，进入根因、纠正/预防措施和完成证据。
5. 独立验证人通过或退回返工；通过且有效性评价完整后，有权角色关闭问题。

## 10. 管理员操作

### 10.1 日常检查

管理员应定期检查：

- 用户部门、岗位和角色映射
- 企业资料、制度和证照完整性
- 证照提醒扫描结果
- 办事入口有效性
- 工作平台模块启用状态
- 企业微信审批同步异常
- 文件上传和下载异常
- 打印快照生成情况
- 计划生成/对账失败、任务消息投递和逾期升级
- 检查转问题失败队列、CAPA 逾期、验证返工和关闭拒绝审计
- 存量迁移批次数量、失败行和来源只读回链

### 10.2 审批异常

审批状态长时间不同步时：

1. 先在企业微信审批中心查找审批单。
2. 核对系统记录是否已有审批实例。
3. 使用审批对账功能。
4. 对失败实例执行重试。
5. 保留失败原因和处理记录。

### 10.3 权限异常

发现用户能看到不属于其船舶或职责范围的数据时：

1. 立即停止继续传播或处理该数据。
2. 记录账号、模块、记录编号和时间。
3. 检查企业微信部门与岗位。
4. 检查模块角色配置。
5. 修复后使用不同角色账号复测。

## 11. 常见问题

### 11.1 页面提示无权限

- 确认是否使用正确企业微信账号。
- 确认岗位或部门是否刚发生变化。
- 点击重新认证。
- 仍无权限时联系管理员检查角色映射。

### 11.2 保存后列表没有记录

- 清空筛选条件。
- 检查日期范围。
- 返回模块首页重新进入。
- 不要立即重复新建，先确认是否已经生成。

### 11.3 企业微信审批没有打开

- 确认在企业微信内打开系统。
- 检查 JS-SDK 是否加载成功。
- 到企业微信审批中心确认是否已生成。
- 记录错误提示交管理员处理。

### 11.4 附件无法上传或预览

- 确认文件上传已完成。
- 检查文件是否过大或格式不受支持。
- 弱网下使用原条目的“重试”，不重复创建业务记录。

### 11.5 打印后没有下载

- 采购模块应检查是否打开了新窗口。
- 工作平台当前可能只生成快照。
- 记录业务编号和生成时间，请管理员查询文件记录。

### 11.6 数据看板与列表不一致

正式业务数据以列表、记录详情、审批轨迹和导出结果为准。首页演示卡片不作为审计依据。

## 12. 操作与合规要求

1. 不得代替他人提交、签认或审批。
2. 不得删除、替换或伪造现场证据。
3. 发现问题必须如实记录，不能仅修改状态。
4. 审批意见应具体、可追溯。
5. 船舶、人员、日期和设备信息必须与实际业务一致。
6. 系统缺少专用字段时，仍须执行法律法规和公司安全管理制度要求。
7. 导出的 PDF、附件和截图应按公司信息安全制度保存和传输。

## 14. 版本维护

以下变化发生后应同步更新本手册：
