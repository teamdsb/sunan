# M8 安全管理上线培训材料

## 培训对象与时长

| 对象 | 建议时长 | 必会内容 |
|---|---:|---|
| 船员/检查人 | 45 分钟 | 消息深链、待办、检查项、拍照/定位/签名、弱网恢复 |
| 措施责任人/验证人 | 45 分钟 | 根因、纠正/预防措施、证据、独立验证、返工与关闭门槛 |
| 部门/安全管理员 | 60 分钟 | 主数据、计划/模板、数据范围、对账、转单补偿和导出 |
| 系统管理员/运维 | 60 分钟 | 迁移批次、消息 outbox、监控、回滚、Hypercare 和审计 |

## 演示脚本

1. 以计划负责人创建一次性检查计划，设置两位检查人且完成规则为 `all`。
2. 执行生成，展示同一任务在待办、日历和企业微信消息中的一致链接。
3. 两位检查人分别录入不符合结果、照片、定位和签名，演示未满足门槛时无法汇总。
4. 汇总后查看去重问题及原检查项回链。
5. 创建 CAPA，录入根因和纠正/预防措施，上传证据并由验证人退回一次。
6. 补充后验证通过，填写有效性评价并关闭，展示全部动作轨迹。

## 必做练习

- 船员账号尝试访问他船记录，确认 403/无权页不泄露摘要。
- 措施责任人尝试验证自己的措施，确认职责隔离。
- 重复点击任务生成/提交，确认不产生重复对象。
- 切换弱网导致上传或消息失败，使用原记录重试并查看失败原因。
- 生成 PDF/导出，再使用无权账号尝试下载。
