# 系统架构概览

## 整体架构

苏南船舶管理系统采用前后端分离架构，以企业微信 H5 自建应用形式交付。

```
┌─────────────────────────────────────────────────────────┐
│                     企业微信客户端                        │
│   ┌─────────────┐    ┌─────────────────────────────┐   │
│   │  工作台入口  │    │   H5 WebView (React SPA)    │   │
│   └──────┬──────┘    └──────────────┬──────────────┘   │
└──────────┼───────────────────────────┼──────────────────┘
           │ 打开应用                   │ API 请求 (HTTPS)
           ↓                           ↓
┌──────────────────┐       ┌───────────────────────────┐
│  企业微信开放平台  │       │      NestJS 后端 API      │
│                  │       │                           │
│  - OAuth2 认证   │←─────→│  - 认证模块 (JWT)         │
│  - JS-SDK 签名   │       │  - 企业微信集成服务        │
│  - 消息推送      │       │  - 业务模块 (REST)         │
│  - 通讯录 API    │       │  - 文件服务 (OSS代理)      │
└──────────────────┘       │  - 定时任务 (证书扫描)     │
                           └───────┬───────────────────┘
                                   │
              ┌────────────────────┼───────────────┐
              ↓                    ↓               ↓
    ┌─────────────────┐  ┌──────────────┐  ┌────────────┐
    │   PostgreSQL    │  │    Redis     │  │  阿里云 OSS │
    │                 │  │              │  │            │
    │  - 业务数据     │  │ - access_    │  │ - 证书文件 │
    │  - 用户数据     │  │   token 缓存 │  │ - 附件     │
    │  - 证书元数据   │  │ - 会话缓存   │  │ - 图片     │
    └─────────────────┘  └──────────────┘  └────────────┘
```

## 四大板块

| 板块 | 路由前缀 | 里程碑 | 定位 |
|---|---|---|---|
| 我的 | `/my` | M1 | 个人与企业资料中心 |
| 办事 | `/office` | M2 | 统一服务端口入口 |
| 采购管理 | `/procurement` | M3 | 采购审批与统计 |
| 工作平台 | `/workbench` | M4 | 部门业务承载 |

## 认证与授权流程

```
用户打开企业微信应用
        │
        ↓
React SPA 初始化
        │
        ├── 未认证 ──→ 重定向到企业微信 OAuth2
        │                     │
        │            企业微信颁发 code
        │                     │
        │            后端 /auth/wecom/callback
        │                     │
        │            换取 UserId → 生成 JWT
        │                     │
        └── 已认证 ←─── 存储 JWT (localStorage)
                │
                ↓
        路由权限检查 (基于职务/部门)
                │
                ↓
           渲染对应模块
```

## 文件上传流程（阿里云 OSS 预签名模式）

```
前端                后端                 阿里云 OSS
  │                  │                      │
  │  POST /files/presign                    │
  │─────────────────→│                      │
  │                  │  生成预签名 URL        │
  │                  │─────────────────────→│
  │                  │  返回 presignedUrl    │
  │←─────────────────│                      │
  │                  │                      │
  │  直接 PUT 文件到 OSS                     │
  │─────────────────────────────────────────→
  │                  │                      │
  │  POST /files/callback (oss_key, meta)   │
  │─────────────────→│                      │
  │                  │  写入文件元数据到 DB   │
  │                  │                      │
  │  返回 fileRecord  │                      │
  │←─────────────────│                      │
```

## 证书到期提醒流程

```
NestJS @Cron('0 9 * * *')  每日 09:00 执行
        │
        ↓
查询 certificates 表
找出 expiry_date 在提醒阈值内的记录
（证书: 30天内，合同: 90天内）
        │
        ↓
对比 certificate_reminders 表
确定新增/更新的提醒记录
        │
        ↓
写入 certificate_reminders（status: pending）
        │
        ↓
调用企业微信消息推送 API
发送应用消息给相关负责人
        │
        ↓
更新 certificate_reminders（status: sent）
```
