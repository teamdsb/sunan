- 22/22 migration 可在空 PostgreSQL 依赖逆序 down，再全量 up；重复 up 返回空集。

## 生产范围说明

生产备份、`classify`、实际数量/关联/状态核对和备份恢复演练未在本地环境执行。用户已明确这些生产现场事项不纳入本次 M8 归档核查；如目标环境存在对应历史来源，仍应在实际变更窗口按 runbook 判断和执行，不得引用本地 0/0 或合成数据作为生产数量证据。
