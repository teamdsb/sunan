## 4. 全链路、权限与失败恢复

- 主链：计划 -> 任务 -> 两人检查 -> 去重不符合 -> CAPA -> 证据 -> 验证返工 -> 验证通过 -> 关闭。
- 权限：船员跨船、非参与人、旧责任人转移后动作、措施责任人自验、普通执行人关闭重大问题均被拒绝；管理员敏感查看留审计。
- 证据：附件绑定/解除、签名哈希、定位失败说明、真 PDF、导出队列/重试和无权下载有自动化证据。
- 弱网/失败：文件上传失败重试、消息网络失败同 delivery 重试、转单失败 reconcile、worker 并发只领取一次。
- 重复/并发：计划并发生成、检查并发转单、迁移并发重放和 OAuth 深链恢复均有回归。
- 性能：100 条存量迁移 550ms（测试预算 < 10s）；Web production build 保持任务、检查/CAPA、主数据的路由级 chunk。
