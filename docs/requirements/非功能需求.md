# 非功能需求

## 性能

1. 常规列表接口在 500 条以内数据场景下响应时间目标小于 500ms。
2. 文件预签名接口响应时间目标小于 300ms。
3. 提醒扫描任务在 1 万条证书以内应在 5 分钟内完成。

## 可用性

1. 工作时间内核心服务可用性目标不低于 99.9%。
2. 企业微信 H5 页面在主流 iOS/Android 企业微信版本可正常使用。
3. 关键列表页在弱网下提供加载态和重试能力。

## 安全

1. 所有接口必须鉴权，公开接口仅限健康检查和 OAuth2 回调。
2. 文件对象默认私有访问。
3. 审计日志覆盖重要写操作和提醒确认动作。

## 可维护性

1. 规格、测试、实现三者必须可追溯。
2. OpenAPI 文档需可用于 mock 与类型生成。
3. 数据库变更必须通过 migration 管理。
