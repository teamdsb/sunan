# M6 逐条需求对照表（基于 2026-04-22 代码审计）

## 1. 说明
- 基线文档：`docs/需求文档.md`
- 基线代码：`apps/api`、`apps/web`（截至 2026-04-22）
- 状态定义：
  - `✅ 达成`：需求已在代码与路由/接口中闭环
  - `🟡 部分达成`：已有能力，但与需求仍存在字段或行为差距
  - `❌ 未达成`：需求在当前代码中无对应实现
  - `🔒 阻塞`：按 M6 规则明确 blocker，未补料前禁止开发

## 2. 汇总结论
- 总体：四大板块主框架与大部分主链路已落地，但尚未达到“需求文档全部功能 100% 对齐”。
- 当前关键缺口（P0/P1）：
  - `财务板块`（`finance_business_board`）处于 blocker（`🔒`）
  - 业务部多张表字段与需求不一致（签船/垃圾/污油水/生活污水）
  - 总经办会议与培训中的高保真行为（视频群组建、系统签到、会议照片、A3 打印、学习进度）证据不足
