# 里程碑 9 需求文档：专业安全业务深化与体系完善

## 1. 文档定位

M9 以 M8 已验收的权限、流程、证据、主数据、计划任务和 CAPA 为前置条件，将人员、船舶作业、应急、设备、文件和内审等专业安全业务落成可执行、可追溯、可归档的内部管理链路。用户于 2026-07-12 决定暂停 M9；本文保留为可恢复需求基线，不代表已排期或已启动。

M9 不接通海事监管、AIS、CCTV 等外部系统。监管事项采用内部登记、人工上报和回执归档。

## 2. 里程碑目标

### 2.1 主目标

- 建成船员任职、资格、健康、调配、交接、培训、考试和熟悉职责。
- 建成航次安全校验及主要高风险船舶作业许可。
- 建成应急计划、训练、演习、评价、应急事件、事故险情和防台链路。
- 建成设备树、维护计划、缺陷、修理、备件和采购联动。
- 建成安全责任、费用、指定人员监督、船长复查和管理评审。
- 建成受控文件、分发回执、内部审核、报告、统计和档案。
- 将各领域发现的问题统一接入 M8 CAPA。

### 2.2 成功标准

1. 船员上岗和航次审批可校验证书、健康、任职、培训和熟悉职责。
2. 高风险作业具备申请、许可、检查、检测、监护、执行、签名和关闭。
3. 应急计划可生成训练或演习任务，评价问题可进入 CAPA。
4. 事故险情具备快报、调查、原因、措施、审阅和结案。
5. 设备维护可从计划追踪到任务、缺陷、修理、采购、备件和验收。
6. 安全费用可关联采购和预算使用，但不重复建设采购审批。
7. 内审发现可自动生成不符合项，报告可归档和分发。
8. 外部监管事项可登记人工上报状态和回执，无外部接口依赖。

## 3. 前置条件

- M8 Wave 7 已通过验收。
- 安全主数据已完成必要的数据治理。
- 统一任务、证据、权限和 CAPA 服务处于生产可用状态。
- M9 Wave 1 已对 M8 进行基线回归，未解决的 P0 缺陷不得带入后续 Wave。

## 4. 范围说明

### 4.1 纳入范围

#### 人员安全

- 船员档案、任职、上船、下船和调配。
- 证书、健康和岗位资格有效性。
- 工作交接、未结任务和问题转移。
- 培训需求、计划、签到、学习、考试、补考和评价。
- 熟悉职责清单、多人签认和开航前置状态。
- 岸基人员安全职责、资质和考核。

#### 船舶作业

- 航次计划与安全校验。
- 开航前检查和重大问题阻断。
- 燃油审批后自动生成供受油检查任务。
- 有限空间、明火、危险货物和高空舷外作业许可。
- 岸电、油污水、垃圾、生活污水和环保单证。
- 值守、巡查、交接和漏检提醒。
- 海图更新通告来源与版本核验。

#### 应急、事故与防台

- 年度应急计划、训练和演习任务。
- 船舶、岸基和船岸联合演习。
- 演习评价、改进任务和 CAPA。
- 应急事件启动、指挥、过程日志、审阅和结案。
- 事故险情快报、调查、损失、原因、责任和措施。
- 防台预警、会议、检查、部署、动态、解除和小结。

#### 设备、修理与备件

- 船舶设备树、分类、参数和周期模板。
- 年度和月度维护计划。
- 多人执行、船长确认和岸基审查。
- 设备缺陷、修理、厂修、报价、验收和结算关联。
- 备件字典、申领、发放、领用、退库、盘点和结存。
- 修理和备件需求与采购管理联动。

#### 安全治理

- 安全责任书、年度签订和履职检查。
- 安全费用计划、使用登记、预算占用和采购关联。
- 指定人员年度或季度监督计划、检查和问题转单。
- 船长复查、复查会议、报告和岸基审阅。
- 管理评审输入、决议、行动项和有效性评价。

#### 文件、内审、统计与档案

- 内部受控文件变更、审批、版本、替换和修订说明。
- 外来文件登记、适用性评审、更新和停用。
- 文件分发、阅读确认和水印导出。
- 内审计划、审核组、首末次会议、方案、个人记录和汇总。
- 船舶审核报告、公司总报告、分发和归档。
- 人员、培训、问题、设备、文件和内审统计。
- 统一档案目录、保管期限、只读冻结和访问审计。

#### 人工监管上报留痕

- 外部检查、处罚、通知和上报事项内部登记。
- 上报材料、上报时间、经办人、渠道、状态和回执。
- 外部问题可人工转为内部问题或不符合项。
- 不建设外部平台接口。

### 4.2 不在 M9 范围

- 海事监管平台 API。
- AIS、CCTV、装载仪或能耗设备实时数据接入。
- 独立微信小程序。
- 完整 HR 薪酬、招聘和劳动合同系统。
- 完整财务总账、会计凭证和资金支付系统。
- 预测性维护、机器学习风险评分和复杂数字孪生。

## 5. 关键决策

### 5.1 资格校验使用规则快照

航次或上岗校验应保存当时的证书、健康、任职、培训和问题状态快照，避免后续主数据变化导致历史结论不可解释。

### 5.2 高风险作业使用专用聚合流程

高风险作业复用 M8 通用任务、证据和步骤能力，但必须拥有专用字段、检查表和关闭规则，不得只使用摘要文本。

### 5.3 设备需求复用采购

修理和备件需求通过来源关联进入现有采购流程。采购仍是金额、审批和采购单真源，设备模块负责技术需求、到货验收和缺陷关闭。

### 5.4 内审发现复用 CAPA

内审、管理评审、事故、设备和人工监管登记发现的问题统一进入 M8 问题与 CAPA 中心，不再建设平行整改表。

### 5.5 外部上报只记录人工事实

系统记录用户实际执行的上报渠道和回执，不自动推断外部平台已接收或已通过。

## 6. Wave 规划

### Wave 1：M9 规格冻结与 M8 基线回归

- 冻结专业领域边界、状态、权限和关联。
- 回归 M8 权限、任务、证据、CAPA 和性能。
- 阻断未关闭 P0 缺陷。

### Wave 2：人员安全与培训资格

- 落地任职、调配、交接、健康和资格。
- 落地培训需求、计划、签到、考试和评价。
- 落地熟悉职责和开航前置状态。

### Wave 3：航次与船舶高风险作业

- 扩展航次安全校验和开航检查。
- 落地燃油、有限空间、明火、危险货物、高空舷外等许可。
- 完善环保作业、值守巡查和海图核验。

### Wave 4：应急、事故险情与防台

- 落地应急计划、训练、演习和评价。
- 落地应急事件与事故险情。
- 落地防台全过程。

### Wave 5：设备维护、修理、备件与采购联动

- 落地设备树、周期模板、年度月度计划和执行。
- 落地缺陷、修理、厂修和验收。
- 落地备件库存及采购联动。

### Wave 6：安全责任、费用与管理复查

- 落地责任制和履职检查。
- 落地安全费用计划和采购关联。
- 落地指定人员、船长复查和管理评审。

### Wave 7：受控文件、内审、统计与档案

- 落地文件变更、分发、回执和水印。
- 落地完整内审链路和报告。
- 落地全域统计、人工监管留痕和档案中心。

### Wave 8：全域联调、验收、上线与手册更新

- 完成跨领域联调、迁移、权限、性能和弱网测试。
- 完成企业微信真机回归。
- 更新操作手册、上线材料和 Hypercare。

## 7. 验收要求

1. 每个专业业务必须说明如何复用 M8 任务、证据、权限和 CAPA。
2. 每个高风险作业必须有结构化检查表和必需证据规则。
3. 每个跨模块自动化必须有幂等、失败补偿和审计。
4. 人员资格和航次校验必须覆盖临界日期、证书失效和未完成熟悉职责。
5. 设备库存必须覆盖并发出入库、盘点差异和负库存拦截。
6. 文件版本、分发和内审报告必须可追溯且不可静默替换。
7. 外部上报状态必须标注为人工录入，不得显示为接口同步。
8. M9 结束时更新 `docs/handbook/苏南船舶管理系统操作手册.md`。
