# 里程碑 1 需求文档："我的"模块

## 目标

交付企业微信工作台中的 "我的" 模块，覆盖企业资料、企业制度、电子证照、证书提醒、船舶监控和设置六个子功能。

## 范围

| 功能 | 范围说明 |
|---|---|
| 企业资料 | 列表、详情、附件管理 |
| 企业制度 | 列表、详情、版本历史、发布 |
| 电子证照 | CRUD、分组查询、附件管理 |
| 证书提醒 | 看板、列表、详情、确认、手动扫描 |
| 船舶监控 | 入口列表、按船舶查看 |
| 设置 | 获取与更新当前用户偏好 |

## 前置依赖

1. 企业微信 OAuth2 登录打通。
2. JS-SDK 签名接口可用。
3. PostgreSQL、Redis、OSS 基础设施可用。
4. 引用数据种子初始化完成。

## 验收标准

1. 用户可在企业微信内静默登录并进入 `/my`。
2. 六个子功能均有可访问页面和稳定 API 规格。
3. 证照可按船舶、车辆、人员查询，并展示到期状态。
4. 提醒系统可按规则生成和确认提醒。
5. 文件上传采用预签名模式，不经后端中转大文件。

## 不在本里程碑范围

- 办事模块
- 采购管理模块
- 工作平台模块
- 企业微信审批流集成
