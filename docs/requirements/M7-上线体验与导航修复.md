# 里程碑 7 需求文档：上线体验与导航修复（历史归档）

## 1. 文档定位

M7 是 M1-M6 上线后的体验、可用性和企业微信 H5 直达收口里程碑，已于 2026-07-10 验收完成并归档。它不新增安全管理专业业务，而是优先修复当前四大板块中已经暴露的文件上传、页面视觉、返回路径、PDF 导出、工作台导航和企业微信直达问题。

原安全管理底座里程碑后移为 M8，原专业安全业务深化里程碑后移为 M9。

## 2. 里程碑目标

- 恢复并验证文件上传、附件绑定、预览、下载和采购 PDF 导出链路。
- 收敛“我的”“办事”“采购”“工作台”四大板块的移动 H5 视觉密度和返回路径。
- 修复办事分类切换、搜索框视觉、工作台模块导航和锚点跳转问题。
- 验证企业微信工作台直达、消息深链、认证恢复和弱网反馈。
- 在 M7 验收通过后，再重新启动 M8/M9 安全管理升级。

| `M7-R03` | 办事板块分类切换出现 CSS 空白 | 办事 | P0 |

## 4. Wave 规划

| Wave | 主题 | 核心范围 |
|---|---|---|
| Wave 1 | 上传与我的板块视觉 | 文件上传修复、上传组件错误态、我的模块密度收敛 |
| Wave 2 | 办事 CSS 与搜索体验 | 分类切换空白修复、搜索框视觉收敛 |
| Wave 3 | 采购返回、附件与中文 PDF | PDF 中文模板、返回按钮、附件区优化 |
| Wave 4 | 工作台返回、密度与导航 | 工作台返回路径、组件高度、模块导航和锚点 |
| Wave 5 | 企业微信直达回归 | 四大板块直达、认证恢复、深链返回、弱网反馈 |
| Wave 6 | 最终收口与后续门禁 | 测试、文档索引、验收归档、M8/M9 重启判断 |

## 5. 验收要求

1. 文件上传链路符合 `docs/specs/common/file-upload-spec.md`，不绕过 OSS 预签名模式。
2. 四大板块直接打开目标 URL 可完成认证恢复、状态初始化和页面渲染。
3. 所有有跳转下一页的核心页面都有明确返回路径。
4. 采购 PDF 中文可读，A4 版式、金额、审批意见和附件引用正确。
5. 办事分类和工作台模块导航不再出现错误空白、同跳或锚点失效。
6. 移动端 320px 到常见企业微信视口无横向滚动、文本重叠或按钮挤压。
7. M7 结束时无未关闭 P0/P1，才允许启动 M8。
