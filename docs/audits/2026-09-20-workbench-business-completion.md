# 考勤、个人学习与燃油月报补齐记录

## 范围

用户要求补齐船舶监控核查中发现的三项业务缺口，并明确手册需要更新的截图。本轮完成本地实现和验证，不包含生产部署。原监控修复保留，M9 继续暂停。当前规则见 [业务规则](../specs/workbench/business-reporting.md)，接口见 [平台 API](../specs/workbench/api/workbench-platform-api.yaml)。

## 完成内容

| 缺口 | 补齐行为 |
|---|---|
| 考勤导出只有月份等元信息 | 页面与导出共用实际记录，增加人员汇总、逐日考勤、工时及缺失标识；XLSX 三张表，PDF 中文明细；月份按上海时区，导出冻结权限范围 |
| 学习只有整条记录手填进度 | 选择真实企业成员下发冻结材料，成员本人逐项确认，自动统计个人进度、课程完成率及学时；个人详情/打印/导出隔离，管理人员汇总；船务课程完成自动关闭，总经办课程完成后可提交审批 |
| 燃油月报依赖手填月耗 | 批准后登记实收，月末测量余量，自动承接上月期末并计算月耗；缺数据标为待核对，分油品和单位统计，显示低余量提醒，支持更正与 Excel 导出 |

同时修复：通用动作/审批回调整体写回可能覆盖专用数据、学习待办不随个人完成更新、审批人员学时与实际下发不一致、测量更正丢失期初或阈值、学习上传在记录锁与外键之间等待、打印生成后未打开文件、月份切换短暂显示旧统计。

## 验证

- 本地浏览器连接真实 Nest 工作平台模块、真实独立 PostgreSQL，仅认证与对象存储采用验收替身。完成考勤 XLSX/PDF 生成及下载、学习下发/成员确认/完成学时、燃油实绩保存/测量更正/月报下载、学习统计下载。
- 验证例：期初 100 L + 实收 50 L − 月末 30 L = 月耗 120 L；更正月末为 20 L 后月耗 130 L，原提醒阈值保留。
- 390 × 844 手机视口考勤与燃油页面无水平溢出；已检查桌面学习及手机页面截图、中文 PDF 输出，确认真实姓名/船名/工时出现在报告中。
- 专项 PostgreSQL 回归包括：上海月份边界、实际 XLSX 解析、导出范围隔离、学习越权/幂等/打印隔离、学习附件锁定上传、课程自动关闭、燃油结转及并发更正。
- 最终自动化：API 单元 28 套件 / 154 项，PostgreSQL 集成 20 套件 / 117 项，Web 60 文件 / 266 项，共 537 项通过。导出专项 2 个套件 / 7 项再次通过。
- 最终 `pnpm build`（Web + API）、API lint、工作平台 OpenAPI 校验、281 份 Markdown 索引及 `git diff --check` 均通过。当前 Node 24 与仓库声明 Node 20 的 engine 提示仍存在，未导致这些检查失败。
- 全量首轮同时运行造成资源争用，已停止并改为单元/集成/Web 顺序执行；中途发现的空船舶类型检查和测试样本缺字段均修正后重跑通过，未放宽测试超时或忽略失败。
- 验收截图位于 `output/playwright/workbench-business/`，报告样例与命令日志位于 `/tmp/sunan-workbench-check/`。临时测试认证脚本、服务和浏览器已移除或停止。

## 边界与手册

学习进度依据成员主动确认材料，未采集视频播放时长或考试成绩；燃油计算依据实际记录，原始测量仍需登记，未连接油表设备或发送企业微信提醒。历史缺失工时、未分配到真实成员的学习台账、缺船舶关联的旧加注申请不会自动编造数据。

Markdown 手册第 8.7、8.9、8.10 节已同步。需要替换及新增的图号、文件名、截图账号与关键画面见 [截图更新清单](../handbook/2026-09-20-截图更新清单.md)。Word 版尚未按本轮重新生成，建议真实业务截图齐备后统一更新。

本轮未验证生产企业微信三端或真实审批回调，也不代表已补齐原始核查中的所有其他业务（如车辆燃油、会议签到自动采集或 GPS 围栏）。
