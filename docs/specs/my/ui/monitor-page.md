# 船舶监控页面规格

## 适用路由

- `/my/monitors`
- `/my/monitors/:vesselId`

## 页面目标

提供按船舶访问监控系统的统一入口，减少用户查找第三方地址的成本。

## 列表页

### 页面组成

1. 船舶卡片列表
2. 每艘船的监控入口数量
3. 最近验证状态提示

## 详情页

### 页面组成

1. 当前船舶信息
2. 监控入口列表
3. 外链打开或嵌入入口

## 交互规则

1. 普通用户仅看到启用入口。
2. `accessMode = embed` 时优先内嵌，否则新开 WebView。
3. 外链不可用时提示联系管理员，不暴露技术错误细节。

## 验收要求

- 按船舶路由直达时能独立加载
- 监控入口排序稳定
- 移动端打开第三方页面行为可预期
