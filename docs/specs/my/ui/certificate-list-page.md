# 电子证照列表页规格

## 适用路由

- `/my/certificates`

## 页面目标

按船舶、车辆、人员或证书类型查看证照，并快速定位临期项。

## 页面组成

1. 顶部筛选栏：`ownerType`、持有对象、证书类型、状态、关键字。
2. 分组切换：按持有对象 / 按证书类型。
3. 列表区：证书标题、持有对象、到期日期、剩余天数、状态。
4. 浮动操作：有权限用户可新增证照。

## 交互规则

1. 默认分组模式读取用户设置 `certificateGroupBy`。
2. 临期和逾期证照使用显著颜色区分。
3. 点击列表项进入详情；返回时恢复筛选和滚动位置。

## 验收要求

- 同一组内排序默认按到期日升序
- 合同类与普通证书展示同一列表但标签不同
- 无结果时保留筛选条件并提示调整
