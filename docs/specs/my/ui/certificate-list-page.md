# 电子证照列表页规格

## 适用路由

- `/my/certificates`

## 页面目标

按船舶、车辆、人员或证书类型查看证照，并快速定位临期项。

## 页面组成

1. 顶部筛选栏：`ownerType`、持有对象、证书类型、状态、关键字。
2. 统计分组：固定按证书类型，不按持有对象分组。
3. 列表区：证书标题、持有对象、编号、签发/到期时间、签发机构、附件数、提醒配置和状态。
4. 顶部操作：有权限用户可在页面顶部点击“新增证照”。

## 交互规则

1. 分组固定为证书类型，历史 `groupBy=owner` 查询参数会自动归一为 `groupBy=type`。
2. 临期和逾期证照使用显著颜色区分。
3. 点击列表项进入详情；返回时恢复筛选和滚动位置。

## 验收要求

- 同一组内排序默认按到期日升序
- 合同类与普通证书展示同一列表但标签不同
- 无结果时保留筛选条件并提示调整
