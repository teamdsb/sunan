# 电子证照详情页规格

## 适用路由

- `/my/certificates/:id`

## 页面目标

展示证照完整元数据、附件和提醒信息，承载编辑入口。

## 页面组成

1. 证照基本信息卡片
2. 持有对象信息卡片
3. 附件区
4. 提醒信息区：提前天数、最近提醒状态

## 交互规则

1. 到期日变更后，页面提示会影响提醒规则。
2. 附件支持预览、下载、删除和补传。
3. 具备权限时显示编辑按钮和删除按钮。

## 验收要求

- 详情数据与列表关键字段一致
- 附件顺序与后台 `sort_order` 一致
- 删除成功后返回列表并提示
