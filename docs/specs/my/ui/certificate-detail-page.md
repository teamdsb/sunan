# 电子证照详情页规格

## 适用路由

- `/my/certificates/:id`

## 页面目标

展示证照完整元数据、附件和提醒信息，承载编辑入口。

## 页面组成

1. 证照基本信息卡片
2. 持有对象信息卡片
3. 附件区：文件名、类型、大小、预览和下载
4. 提醒信息区：企业微信提醒开关、可选负责人、提前天数和最近提醒状态

## 交互规则

1. 签发时间和到期时间必须使用日期时间控件；接口拒绝只有日期的值。
2. 到期时间或提醒配置变更后，页面提示会影响提醒规则，证照保存成功后自动触发提醒检查。
3. 附件支持在应用内统一弹窗预览、下载和补传；预览和下载 URL 必须通过证照与附件绑定关系接口获取。
4. 具备权限时显示完整编辑表单和保存按钮，保存成功或失败都给出明确提示。

## 验收要求

- 详情数据与列表关键字段一致
- 附件顺序与后台 `sort_order` 一致
- PDF、图片可直接预览；不支持在线预览的格式展示文件信息和下载入口
- 删除成功后返回列表并提示
