# 设置页面规格

## 适用路由

- `/my/settings`

## 页面目标

管理用户个性化偏好，范围仅限里程碑 1 已实现能力。

## 页面组成

1. 默认视图设置
2. 证照分组方式
3. 提醒推送开关
4. 系统信息区：版本号、缓存刷新入口

## 交互规则

1. 所有设置项修改后即时保存。
2. 保存失败时回滚并提示错误。
3. 关闭推送前显示影响说明。

## 验收要求

- 首次进入可展示默认值
- 切换设置后返回相关页面立即生效
- 页面无需复杂滚动即可完成全部设置
