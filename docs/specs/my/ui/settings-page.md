# 设置页面规格

## 适用路由

- `/my/settings`

## 页面目标

管理个人提醒偏好；env 管理员还可进入用户管理及通知应用设置。

## 页面组成

1. 默认视图设置
2. 证照分组方式
3. 提醒推送开关
4. 系统信息区：版本号、缓存刷新入口

## 交互规则

1. 个人偏好修改后即时保存；通知配置必须显式保存或确认清除覆盖。
2. 保存失败时回滚并提示错误。
3. 关闭推送前显示影响说明。

## 验收要求

- 首次进入可展示默认值
- 切换设置后返回相关页面立即生效
- 移动端允许纵向滚动，320px无横向溢出；通知表单保留输入、错误和冲突恢复入口

## M9 W4 推送设置

仅env管理员可见“企业微信推送应用”卡片。主CorpID/AgentID只读，Secret永不回填；同企业通知AgentID和Secret可保存，Secret留空保留，AgentID变化需重填。明确清除覆盖才恢复主应用。

页面显示当前来源、AgentID、配置版本和密钥/解密故障。读取失败不能显示为正常默认；重新加载显式恢复最新版本。表单编辑期间保留最初版本，409时提示重载，不能用后台刷新后的版本静默覆盖。验证连接与发送定向测试区分结论，定向测试只指定一个有效UserID且不修改线上配置。

失败/不确定/超时投递列出实际应用与版本；管理员可人工核对已送达/未送达，再对确认失败的业务消息手动重试。密钥轮换需env预先配置新旧独立密钥，界面不显示密钥值。所有操作失败均有明确反馈。接口见[settings-api.yaml](../api/settings-api.yaml)，证据与未执行现场项见[W4验收](../../../acceptance/M9-wave-4.md)。
