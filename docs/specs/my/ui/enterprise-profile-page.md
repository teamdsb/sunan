# 企业资料页面规格

## 适用路由

- `/my/enterprise-profile`
- `/my/enterprise-profile/:id`

## 列表页

### 页面目标

提供企业资料快速查阅入口，支持按分类和状态筛选。

### 页面组成

1. 顶部搜索栏：关键字、分类、状态。
2. 列表区：标题、分类、发布时间、附件数量。
3. 管理入口：有权限用户显示“新建资料”。

### 交互规则

1. 点击列表项进入详情。
2. 草稿状态对普通员工隐藏。
3. 附件存在时显示预览/下载入口。

## 详情页

### 页面组成

1. 基本信息卡片
2. 附件列表
3. 审计信息

附件列表统一提供“预览”和“下载”。预览使用应用内弹窗，并通过企业资料与附件绑定关系接口获取短期 URL；不支持在线预览的格式仍在弹窗中展示文件信息和下载入口。

### 验收要求

- 空列表时显示引导态
- 附件加载失败时支持重试
- 上传前展示允许格式与 20MB 单文件限制
- 删除成功后返回列表页并刷新
