# 证书提醒页面规格

## 适用路由

- `/my/reminders`
- `/my/reminders/:id`

## 看板页

### 页面目标

让用户先看到风险总览，再进入明细处理。

### 页面组成

1. 统计卡片：待处理、已逾期、已确认。
2. 分类统计：按持有对象、按证书类型。
3. 列表摘要：最近提醒若干条。
4. 管理操作：有权限用户可触发手动扫描。

### 交互规则

1. 默认视图模式读取 `reminderViewMode`。
2. 点击统计卡片可带筛选条件跳到列表态。
3. 手动扫描触发后给出异步任务提示，不阻塞页面。

## 详情页

### 页面组成

1. 提醒摘要
2. 关联证照信息
3. 处理记录
4. 确认按钮

### 验收要求

- 已确认提醒状态不可再次操作
- 权限不足时隐藏确认按钮
- 逾期提醒在视觉上明显区别于临期提醒
