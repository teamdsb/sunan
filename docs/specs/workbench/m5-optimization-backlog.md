# 工作平台 M5 优化项清单

## 1. 文档目的

本清单承接 M4 Wave 8 验收结论，沉淀进入 M5 的优化项，作为下一里程碑的实施输入。

## 2. 优先级定义

- P0：上线稳定性与合规风险，必须优先处理。
- P1：影响核心效率与运维质量，应在 M5 主体完成。
- P2：体验与扩展优化，可按资源滚动推进。

## 3. 优化项总表

| 优先级 | 主题 | 问题描述 | 目标产出 |
|---|---|---|---|
| P0 | 企业微信真机回归留痕 | 当前已完成清单冻结，需在目标环境形成 iOS/Android 回归证据 | 真机回归报告、缺陷闭环记录 |
| P0 | 审批桥容错与告警 | 审批回调/对账失败场景需要更强告警与重试治理 | 回调失败告警、重试任务仪表盘 |
| P0 | 权限矩阵自动化校验 | 模块持续增多后，人工校验权限可见性成本高 | 权限回归测试用例与 CI 校验 |
| P1 | 统计口径固化与导出 | 月度统计已可用，导出模板与财务对账自动化待完善 | 固定导出模板、对账校验脚本 |
| P1 | 打印模板标准化 | 各模板打印快照存在格式差异，归档体验可优化 | 统一 A4 打印模板体系 |
| P1 | 可观测与追踪 | 关键链路日志已可用，但缺少统一指标视图 | 工作平台 SLI/SLO 与告警面板 |
| P2 | 前端性能优化 | 构建产物体积较大，需做路由与模块级拆分 | 代码分包与首屏性能优化 |
| P2 | 批量操作能力 | 运营场景需要批量归档、批量导出 | 批量动作 API 与页面交互 |
| P2 | 数据治理 | 历史记录增长后，需归档分层与冷热数据策略 | 数据归档策略与保留周期实现 |

## 4. 建议实施顺序

1. P0：真机回归留痕 + 审批桥容错 + 权限自动化。
2. P1：统计导出/对账 + 打印模板标准化 + 可观测体系。
3. P2：性能优化 + 批量操作 + 数据治理。

## 5. 依赖关系

- 企业微信配置与回调环境：`docs/specs/wecom/workbench-go-live-checklist.md`
- 权限基础：`docs/specs/common/auth-spec.md`
- 工作平台当前规格索引：`docs/specs/workbench/README.md`

## 6. 验收建议

- 每个优化项至少包含：目标、影响范围、回滚方案、监控指标、验收口径。
- P0/P1 项建议纳入里程碑级验收；P2 项可按季度滚动交付。
