# 海图更新模块 UI 规格（M6）

## 1. 路由

- `/workbench/modules/shipping_chart_update`
- `/workbench/modules/shipping_chart_update/new`
- `/workbench/modules/shipping_chart_update/:recordId`

## 2. 页面组

### 2.1 列表页

- 展示更新批次、适用船舶、版本/日期、确认状态、下次计划更新日期
- 支持按船舶、状态、时间区间筛选

### 2.2 新建 / 编辑页

- 录入更新批次
- 选择适用船舶
- 录入版本 / 日期
- 录入更新资源摘要
- 上传附件
- 录入说明

### 2.3 详情页

- 展示本次更新全部信息
- 展示确认人、确认时间
- 展示推导出的下次计划更新日期
- 展示与 `chart_update` 提醒联动状态

### 2.4 打印页

- 输出 `A4-海图更新确认单`

## 3. 关键动作

- 创建
- 提交确认
- 查看提醒联动结果
- 归档

提交确认后页面反馈必须包含：

- `confirmedAt`
- `nextPlannedUpdateDate`
- 各船舶联动结果（成功 / 更新既有提醒 / 失败）
- 失败条目的诊断入口（跳转管理员诊断页并带 `moduleCode=shipping_chart_update`）

## 4. 展示原则

- 船舶范围以标签或清单方式清晰展示
- “下次计划更新日期”必须在确认后显著展示
- 若提醒联动失败，详情页需显示失败提示并跳转管理员诊断
- 若提醒联动处于重试中，详情页需显示“联动处理中”状态并支持刷新

## 5. 验收点

- 海图更新拥有独立列表、录单、详情和打印页
- 确认后可看到下次半年提醒日期
- 提醒联动状态可在详情页追踪
- 联动失败可一键跳转管理员诊断并定位到对应事件
