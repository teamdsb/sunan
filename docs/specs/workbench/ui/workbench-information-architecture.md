# 工作平台信息架构

## 1. 顶层结构

工作平台统一采用以下页面骨架：

1. 工作平台首页
2. 部门模块页
3. 记录列表页
4. 记录详情页
5. 录入/执行页
6. 审批状态页
7. 统计页
8. 打印页

## 2. 页面职责

### 工作平台首页
- 按部门展示模块入口
- 展示待办数、审批数、异常提醒
- 支持从首页直接进入常用模块

### 部门模块页
- 展示单一部门或工作组的模块矩阵
- 支持按模板类型切换查看

### 记录列表页
- 展示统一过滤器、列表、状态标签
- 支持模块维度、船舶维度、时间维度筛选

### 记录详情页
- 展示基本信息、步骤、附件、日志、审批状态
- 允许根据状态触发动作

### 录入/执行页
- 用于创建记录、补录信息、推进步骤、上传现场资料

### 审批状态页
- 仅审批类模块使用
- 展示企业微信审批进度、时间线、同步状态和异常提示

### 统计页
- 仅统计类或需要汇总的模块使用
- 展示汇总卡片、明细导出和口径说明

### 打印页
- 展示 A4/A3 预览与导出入口
- 读取后端打印快照

## 3. 导航规则

- 工作平台首页是唯一一级入口。
- 模块详情必须能从消息、待办、列表三种入口回流。
- 船舶相关模块统一暴露船舶切换器。
