# 财务板块 provisional UI 规格（M6）

## 1. 文档定位

本文件定义 `finance_board` 的 provisional UI 范围，用于让实现阶段知道：

- 哪些页面必须先搭起来
- 哪些内容只能显示为 provisional
- 哪些能力必须依赖统计中心或导出包

## 2. 路由

- `/workbench/modules/finance_board`
- `/workbench/modules/finance_board/new`
- `/workbench/modules/finance_board/:recordId`

## 3. 页面范围

### 3.1 模块首页 / 列表页

已冻结：

- 展示财务板块记录清单
- 支持月份、业务类别、状态筛选
- 展示导出包状态
- 可跳转到详情页与导出包页

### 3.2 新建 / 编辑页

已冻结：

- 允许录入基础摘要与附件
- 所有 provisional 字段必须在 UI 中显式打标

不冻结：

- 最终金额录入交互
- 最终凭证字段

### 3.3 详情页

已冻结：

- 展示基础信息
- 展示附件
- 展示与统计中心的关联结果
- 展示导出包状态

### 3.4 导出包视图

已冻结：

- 展示导出包组成
- 展示关联统计中心结果
- 展示打印快照与附件

## 4. 关键动作

已冻结：

- 创建
- 编辑
- 查询
- 查看导出包

provisional：

- 发起审批
- 金额确认
- 凭证归档

## 5. 显示原则

- 所有 provisional 字段都必须带清晰标签，如“暂行字段”或“待业务确认”。
- 不得在列表页或详情页把 provisional 字段描述成最终业务口径。
- 导出包页面必须显示数据来源：统计中心、附件、打印快照。

## 6. 验收点

- 财务板块拥有独立页面入口，不再只停留在文字边界。
- 页面范围、角色、导出包视图和统计中心关系明确。
- UI 中没有把 provisional 字段伪装为 confirmed 字段。
