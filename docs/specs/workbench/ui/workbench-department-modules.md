# 工作平台部门模块高保真要求（M6）

## 1. 文档定位

本文件将 M5 的“高保真要求”重写为 M6 可直接进入实现的 UI 规格。每个模块或模块组统一从六个维度描述：

- 字段组
- 页面组
- 关键动作
- 打印 / 归档
- 权限 / 审批
- 验收点

说明：

- 同类模块优先复用统一运行时与共享组件。
- 只有页面、字段、动作和打印存在明显差异时，才单独拆出专属页面。

## 1.1 Wave4 Batch A 冻结范围

### 台账类 Batch A

- `goa_training`（岗前/日常/季度/年度培训）
- `goa_meeting`（会议管理）
- `goa_safety_month`（安全月活动）
- `goa_year_plan`（年度工作计划）
- `business_ship_sign`（签船记录表）
- `business_vessel_dynamic`（船舶动态记录表）
- `shipping_training_hours`（船员培训学时统计）
- `shipping_drill`（船舶演练系统）
- `shipping_watch`（值守记录系统）
- `shipping_shore_call`（岸基叫应）
- `shipping_meeting`（船员会议记录）
- `shipping_case_study`（案例警示学习）

### 作业闭环类 Batch A

- `business_operation_flow`（作业人员签到台、接收工作组操作流程、围油栏、船舶垃圾、船舶污油水、生活污水接收记录）
- `zhongchuan_operation_flow`（中船工作组五步作业闭环）
- `pinglu_operation_flow`（平陆运河工作组五步作业闭环）

### Batch A 标准化（WS-4C）

- 打印：每个 Batch A 模块至少冻结 1 个 `A4` 模板；会议模块允许 `A3` 扩展模板。
- 归档：统一通过 `archive` 动作进入归档状态，归档后必须可读取打印快照与关键附件。
- 权限：默认角色为“模块所属部门 + 总经办 + 系统管理员”，不得在页面层绕过统一权限。
- 审批：仅以下 Batch A 模块启用审批模板映射：
  - `goa_training`（仅岗前培训场景）
  - `shipping_watch`
- 验收：每个 Batch A 模块均需满足“字段组 + 页面组 + 关键动作 + 打印/归档 + 权限/审批 + 验收点”六维完整性。

## 2. 总经办

### `goa_training` 培训管理

- 字段组：培训基本信息、讲师与签到、学习资料、学习进度、附件、审批信息
- 页面组：培训列表页、培训新建/编辑页、培训详情页、学习进度视图、打印页
- 关键动作：草稿、提交、补录签到、更新进度、归档；岗前培训额外支持发起审批
- 打印 / 归档：输出 `A4-培训记录`；岗前培训保留审批结果和进度快照
- 权限 / 审批：总经办和系统管理员可管理；岗前培训走 `goa_training_onboarding_v1`
- 验收点：岗前培训可查看学习进度并完成审批；其他培训类型可按时间和类型查询

### `goa_meeting` 会议管理

- 字段组：会议类型、时间地点、参会人、签到、记录、会议照片、群关联信息
- 页面组：会议列表页、会议详情页、签到与照片页、打印页
- 关键动作：创建、签到、补录纪要、归档
- 打印 / 归档：支持 `A4/A3-会议纪要`
- 权限 / 审批：总经办管理，不走审批
- 验收点：视频会议可记录群关联；日常/季度/年度会议可打印归档

### `goa_safety_month` 安全月活动

- 字段组：活动方案、启动宣誓、学习培训、隐患排查、应急演练、专项活动、总结评估、附件
- 页面组：活动列表页、板块式详情页、打印归档页
- 关键动作：创建、更新板块完成状态、上传附件、归档
- 打印 / 归档：支持活动总览打印
- 权限 / 审批：总经办管理，不走审批
- 验收点：8 个板块状态、附件和总结评估完整展示

### `goa_safety_hazard` 安全隐患排查管理

- 字段组：检查对象、检查项、整改要求、整改前照片、整改后照片、审核结论、关闭信息
- 页面组：排查列表页、整改详情页、图片对比页、打印闭环页
- 关键动作：下发排查、提交整改、审核关闭、退回整改
- 打印 / 归档：输出 `A4-隐患闭环单`
- 权限 / 审批：总经办可跨部门查看；系统管理员全量可见；默认系统内闭环
- 验收点：可按部门/作业组筛选；整改前后照片对比清晰

### `goa_year_plan` 年度工作计划

- 字段组：年度、责任部门、节点、完成情况、说明、附件
- 页面组：计划列表页、年度详情页、打印页
- 关键动作：创建、更新节点、标记完成、归档
- 打印 / 归档：输出 `A4-年度工作计划`
- 权限 / 审批：总经办和系统管理员
- 验收点：按年度查看，节点完成情况与附件完整留痕

## 3. 财务部

### `finance_attendance` 统计中心

- 字段组：打卡时间段、定位范围、出差/外派、作业票、劳务费汇总、导出/对账结果
- 页面组：统计总览页、月度列表页、导出中心、对账页、详情抽屉
- 关键动作：查询、导出、发起对账、查看差异
- 打印 / 归档：输出月度统计包
- 权限 / 审批：财务、总经办、系统管理员；默认不走审批
- 验收点：手机打卡、钦州范围定位、上午/下午、出差/外派口径均可查询

### `finance_board` 财务板块（provisional）

- 字段组：仅冻结页面范围、角色、入口、与统计中心关系、导出包边界；业务字段以 provisional 标记
- 页面组：模块首页、清单页、详情页、导出包页
- 关键动作：查询、导出、查看附件；审批动作待确认
- 打印 / 归档：M6 冻结模板占位，不生成最终打印稿
- 权限 / 审批：财务、总经办、系统管理员；审批边界待确认
- 验收点：不伪装成已确认模块，所有未确认字段显式标注 `provisional`

## 4. 业务部

### `business_ship_sign` 签船记录表

- 字段组：客户、船舶、IMO/呼号、船型、总吨、协议编号、费用、收费方式、泊位、装货类型、经手人、带班领导、签订日期、值守船舶
- 页面组：列表页、录单页、详情页、打印页
- 关键动作：创建、编辑、归档
- 打印 / 归档：输出 `A4-签船记录`
- 权限 / 审批：业务部、总经办、系统管理员；不走审批
- 验收点：字段与纸质签船记录 1:1 对齐

### `business_vessel_dynamic` 船舶动态记录表

- 字段组：船名、航次、航线、抵港时间、靠泊时间、靠泊码头、离港时间、备注
- 页面组：列表页、录单页、详情页、打印页
- 关键动作：创建、编辑、归档
- 打印 / 归档：输出 `A4-船舶动态记录`
- 权限 / 审批：业务部、总经办、系统管理员
- 验收点：航次、码头、时间链路完整

### `business_operation_flow` 作业闭环类

适用子模块：

- 作业人员签到台
- 接收工作组操作流程
- 围油栏
- 船舶垃圾
- 船舶污油水
- 生活污水接收记录

- 字段组：基础作业信息、班前会议、作业前检查、巡查记录、完工确认、单证/费用、附件
- 页面组：子模块列表页、四步流程详情页、照片/单证抽屉、打印页
- 关键动作：创建、开始流程、完成步骤、补照片、关闭归档
- 打印 / 归档：按子模块输出对应 `A4-作业闭环单`
- 权限 / 审批：业务部、总经办、系统管理员；默认不走审批
- 验收点：四步流转顺序清晰，照片、单证、费用与作业信息完整

## 5. 船务部

### `shipping_training_hours` / `shipping_drill` / `shipping_watch` / `shipping_shore_call` / `shipping_meeting` / `shipping_case_study`

- 字段组：
  - 培训学时：培训、学时、参与人、附件
  - 演练：计划、演练过程、结果、附件
  - 值守：值班对象、班次、值守情况、附件
  - 岸基叫应：发布内容、船舶、记录回复
  - 会议记录：月度会议、纪要、附件
  - 案例学习：资料、推送对象、完成状态
- 页面组：各模块独立列表页、详情页、打印页；案例学习额外包含推送完成视图
- 关键动作：创建、更新、归档；值守可发起审批
- 打印 / 归档：除案例学习外均支持固定打印稿
- 权限 / 审批：船务部、总经办、系统管理员；值守走 `shipping_watch_v1`
- 验收点：值守区分船员值班系统与船舶值守系统；岸基叫应支持上至下发布；案例学习可追踪完成状态

### `shipping_self_inspection` / `shipping_vessel_inspection` / `shipping_confined_space_operation` / `shipping_oily_water_operation` / `shipping_maritime_safety_check`

- 字段组：检查对象、检查项、整改要求、整改前照片、整改后照片、审核结论、关闭信息
- 页面组：列表页、整改详情页、图片对比页、打印页
- 关键动作：创建、提交整改、审核关闭、退回
- 打印 / 归档：输出各自闭环单
- 权限 / 审批：
  - 自查排查：系统内闭环
  - 船舶检验：`shipping_vessel_inspection_v1`
  - 密闭空间：`shipping_confined_space_v1`
  - 污油水接收作业：`shipping_oily_water_operation_v1`
  - 海事安检：`shipping_maritime_safety_check_v1`
- 验收点：检查项与记录本兼容；整改前后照片和审核结论齐全

### `shipping_attendance`

- 字段组：船员、船舶、班次、签到时间、作业时长、照片、审批结果、统计口径
- 页面组：考勤列表页、录单页、审批状态详情、月统计页、打印页
- 关键动作：创建、提交、发起审批、统计汇总、归档
- 打印 / 归档：输出 `A4-船员考勤表`
- 权限 / 审批：船务部、总经办、系统管理员；走 `shipping_attendance_v1`
- 验收点：下至上提单、审批、统计作业时间、下载/上传照片链路完整

### `shipping_equipment_maintenance`

- 字段组：设备对象、保养类型、保养内容、执行时间、执行人、附件、审批结果
- 页面组：设备列表页、保养记录页、详情页、打印页
- 关键动作：创建、提交、发起审批、归档
- 打印 / 归档：输出 `A4-设备保养记录`
- 权限 / 审批：船务部、总经办、系统管理员；走 `shipping_equipment_maintenance_v1`
- 验收点：兼容轮机、驾驶室、甲板检修养护记录表

### `shipping_voyage_approval`

- 字段组：基本信息、航次核心信息、起始港口、目的港口、预计开航、预计抵达、关键水域、主要任务
- 页面组：审批单列表页、录单页、详情页、审批镜像页、打印页
- 关键动作：创建、发起审批、查看回写、归档
- 打印 / 归档：输出 `A4-航次计划审批单`
- 权限 / 审批：船务部、总经办、系统管理员；走 `shipping_voyage_approval_v1`
- 验收点：审批真源为企业微信，回写状态与详情页一致

### `shipping_fuel_bunkering_approval`

- 字段组：船舶、加油时间、油种、加注量、剩余油量、月油耗、附件、审批结果
- 页面组：燃油列表页、录单页、月报页、详情页、打印页
- 关键动作：创建、发起审批、查看月报、归档
- 打印 / 归档：输出 `A4-燃油加注单`
- 权限 / 审批：船务部、总经办、系统管理员；走 `shipping_fuel_bunkering_v1`
- 验收点：记录每条船加油情况、剩余油量和月报

### `shipping_chart_update`

- 字段组：更新批次、适用船舶、版本/日期、更新资源、说明、附件、确认记录、下次计划日期
- 页面组：海图更新列表页、录单页、详情页、打印页
- 关键动作：创建、提交确认、归档、同步提醒
- 打印 / 归档：输出 `A4-海图更新确认单`
- 权限 / 审批：船务部、总经办、系统管理员；默认不走审批
- 验收点：一次更新确认后可推导下一次半年提醒

## 6. 后勤部

### `logistics_warehouse` / `logistics_office` / `logistics_canteen` / `logistics_dormitory` / `logistics_vehicle_maintenance`

- 字段组：
  - 仓库：财产统计、维护保养、演练计划
  - 办公室：财产、维修保养
  - 食堂：设施设备、维护保养、水电
  - 宿舍：财产、维护保养
  - 车辆：维修保养、月油耗
- 页面组：资产列表页、记录页、详情页、打印页
- 关键动作：创建、更新、归档；车辆维修保养支持审批
- 打印 / 归档：输出各类资产服务单
- 权限 / 审批：后勤部、总经办、系统管理员；车辆维修保养走 `logistics_vehicle_maintenance_v1`
- 验收点：资产服务类页面支持对象维度检索和历史追踪

## 7. 工作组

### `zhongchuan_operation_flow` / `pinglu_operation_flow`

- 字段组：班前会议、工作考勤、作业前检查、巡航记录、完工确认、作业时长、照片
- 页面组：工作组列表页、五步闭环详情页、打印页
- 关键动作：创建、推进步骤、补录照片、归档
- 打印 / 归档：输出对应 `A4-五步作业闭环单`
- 权限 / 审批：工作组成员、总经办、系统管理员；默认不走审批
- 验收点：五步顺序固定，班前会议与工作考勤必须有记录和照片
