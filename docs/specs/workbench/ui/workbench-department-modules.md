# 工作平台部门模块高保真要求

## 总经办

### 培训管理
- 岗前培训必须支持学习进度查看、培训完成审批和 A4 打印。
- 日常/季度/年度培训统一复用台账模板，保留培训类型、时间、讲师、签到、附件、完成状态。

### 会议管理
- 视频会议必须支持会议群关联、签到、会议记录、会议照片和 3 年留存。
- 日常/季度/年度会议支持 A4/A3 打印。

### 安全月活动
- 至少覆盖活动方案、启动宣誓、学习培训、隐患排查、应急演练、专项活动、总结评估、附件留存 8 个板块。

### 安全隐患排查管理
- 必须能按船务部、财务部、业务部、后勤部、作业组五个子维度管理。
- 子项可复用检查整改模板，不单独造数据结构。

### 年度工作计划
- 支持年度维度、责任部门、节点、完成情况、附件与归档。

## 财务部

### 统计中心
- 支持手机打卡、钦州市区范围定位、上午/下午时段、出差/外派。
- 月度生成考勤表、作业票和劳务费统计表。
- 统计口径必须沉淀到统一配置，不允许散落在前端页面逻辑中。

### 财务板块
- M6 已按补料基线落地 `finance_business_board`，支持台账录单、审批、打印与统计。
- 需明确其与“统计中心”的关系：统计中心负责考勤/作业票口径，财务板块负责业务台账与审批留痕。
- 若后续拿到财务部正式样表，应按变更单替换字段字典与打印模板并回归验证。

## 业务部

### 作业人员签到台
- 核心字段：作业人员姓名、作业船名、泊位、签到时间。

### 接收工作组操作流程
- 固定四步：班前会议、作业前检查、巡查记录、完工确认。
- 班前会议必须有记录和照片。
- 作业前检查按现有现场作业安全检查表执行。

### 围油栏
- 核心字段：船名、泊位、代理公司、费用、作业日期。
- 同时保留作业记录、单证与接收记录视图。

### 签船记录表
- 高保真字段必须覆盖：客户姓名、船名、IMO/呼号、船型、总吨、协议编号、费用、收费方式、泊位、装货类型、经手人、带班领导、签订日期、值守船舶。

### 船舶动态记录表
- 核心字段：船名、航次、航线、抵港时间、靠泊时间、靠泊码头、离港时间。

### 垃圾/污油水/生活污水接收
- 核心字段至少覆盖：船名、日期、国籍、泊位、接收数量、单证编号、航次、费用。
- 作业记录中保留内贸/外贸和费用说明等扩展字段。

## 船务部

### 船舶自查排查
- 严格按“由上至下提单 -> 船员落实自查 -> 上传整改前后照片 -> 审核闭环 -> A4 打印”实现。
- 检查项需兼容现有安全隐患排查记录本。

### 船员考勤
- 严格按“由下至上提单 -> 管理员审批 -> 统计作业时间 -> 下载 -> 上传照片”实现。

### 船舶设施设备保养
- 至少承接轮机检修养护记录表、驾驶室及甲板检修养护记录表。

### 船舶检验 / 海事安检系统
- 必须支持按船上传检查单、整改前后照片和闭环记录。

### 船舶演练系统
- 需支持年度应急训练计划及训练记录。

### 密闭空间系统
- 按船管理，兼容每条船一本记录本模式。

### 值守记录系统
- 区分船员值班系统与船舶值守系统。

### 岸基叫应
- 由上至下发布，要求船员记录，按船保留记录表。

### 海图更新
- M5 冻结为 `ledger_form` 模板的最小规格。
- 字段边界限定为：更新批次、适用船舶、版本/日期、说明、附件、确认记录。
- 若后续补充更完整资料，可追加更新资源、替换明细、责任人等字段。

### 污油水接收作业
- 固定四步：班前会议、作业前检查、巡查记录、完工确认。

### 案例警示学习
- 支持上传视频/文件、推送学习、提示完成学习。

### 航次计划审批
- 字段至少覆盖：基本信息、航次核心信息、起始港口、目的港口、预计开航、预计抵达、关键水域、主要任务。
- 审批真源为企业微信审批实例。

### 燃油加注
- 记录每条船加油情况、每月油耗、剩余油量，并生成月报。

## 后勤部

### 仓库
- 支持财产统计、维护保养、演练计划。

### 办公室
- 支持财产、维修保养。

### 食堂
- 支持设施设备、维护保养、水电。

### 宿舍
- 支持财产、维护保养。

### 车辆维修保养
- 支持维护保养和每台车每月油耗记录。

## 工作组

### 中船工作组 / 平陆运河工作组
- 统一采用五步作业闭环：班前会议、工作考勤、作业前检查、巡航记录、完工确认。
- 班前会议必须有记录和照片。
- 工作考勤必须记录船舶信息和作业时长。
