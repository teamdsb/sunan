# 工作平台路由级测试矩阵（M6 Wave7）

## 1. 文档定位

本矩阵用于冻结路由级测试范围，确保 M6 的独立模块页与管理员页不退化为单一路由壳层验证。

## 2. 路由清单

| 路由 | 主要场景 | 必测项 |
|---|---|---|
| `/workbench` | 首页入口与待办聚合 | 角色可见性、模块入口、告警摘要跳转 |
| `/workbench/modules/:moduleCode` | 模块列表 | 筛选器、分页、空态、错误态 |
| `/workbench/modules/:moduleCode/new` | 新建录单 | 字段校验、附件上传、草稿/提交 |
| `/workbench/modules/:moduleCode/:recordId` | 详情与动作 | 状态流转、审批镜像、打印快照、归档 |
| `/workbench/admin/approvals` | 审批实例检索 | 查询维度、详情抽屉、重试/对账动作 |
| `/workbench/admin/exports` | 导出任务 | 任务状态、失败原因、下载结果 |
| `/workbench/admin/reconcile` | 对账任务 | 差异摘要、重跑入口、状态更新 |
| `/workbench/admin/diagnostics` | 诊断事件 | 事件筛选、关联跳转、处理状态 |

## 3. 角色矩阵

| 角色 | 允许访问 | 禁止访问 |
|---|---|---|
| `system_admin` | 全部路由 | 无 |
| `general_office` | 全部业务路由 + 全部管理员路由 | 无 |
| `finance` | 财务相关模块 + `/workbench/admin/reconcile` | 其他管理员路由 |
| 部门业务角色 | 所属模块路由 | 非所属模块与管理员路由 |

## 4. 异常场景

- 无权限访问：返回无权限页或安全重定向，不泄露模块数据
- 会话过期：可重新拉起 OAuth2 后回到原路由
- JS-SDK 初始化失败：页面可展示降级提示并记录诊断事件
- 接口 5xx：显示重试入口，不丢失已输入表单草稿

## 5. 验收门槛

- 路由清单中每条路由至少通过 1 条成功路径与 1 条异常路径
- 管理员四路由必须覆盖筛选、详情、动作三个层面
- 模块详情路由必须覆盖审批、附件、打印三类关键能力
