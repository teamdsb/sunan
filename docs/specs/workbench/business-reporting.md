# 考勤、个人学习与船舶燃油规则

接口定义见 [工作平台 API](api/workbench-platform-api.yaml)。这三项复用工作平台记录及审计日志；本轮无需新增数据库结构迁移，模块目录启动时更新新表单版本，历史记录保留。

## 考勤及导出

- 页面与导出使用同一套当前账号可见记录；按上海时区自然月及可选部门筛选。作废、审批拒绝或取消的记录不计入。
- 统计财务/船务考勤、签到台及已列入的作业流程。优先读取人员 ID/姓名、每人工时，兼容旧姓名名单；无人员 ID 的旧数据按部门及姓名归并，存在同名人员时需核对明细。
- 填写起止时间时优先按时间差计算工时，否则读取实填工时；缺失时为 `null`，不按半天自动推算。跨月作业按记录发生月份归属，不拆分为工资结算。
- 考勤 XLSX 包含“人员汇总 / 逐日考勤 / 考勤明细”；PDF 包含人员汇总与记录明细。人员汇总包含出勤天数、已知工时及缺工时记录数；逐日表保留时段、工时和记录号。
- 异步导出在创建时冻结可见业务快照，任务状态、下载及重试仅创建人和系统管理员可访问。旧队列缺少业务快照时明确失败并提示重新导出，不跨权限重建数据。
- 本轮未建立 GPS 围栏；未知范围按未知处理，不靠船名/地名猜测位置合规。

## 个人学习

支持 `goa_training`、`shipping_training_hours`、`shipping_case_study`。

1. 系统管理员、总经办或船务管理人员创建记录、上传材料，使用 `GET /workbench/learning/people` 选择当前企业中的真实成员。
2. `POST /workbench/records/{id}/learning/publish` 接收 `userIds`（1–500 个、不重复）和 `hours`（每人完成学时，0–1000，最多三位小数）。下发冻结文字内容、附件和人员，更新审批使用的人员/学时字段；已下发、已审批或已有外部审批实例的记录不可重新下发。
3. `POST /workbench/records/{id}/learning/confirm` 仅接受当前成员的 `materialId`。本人逐项确认；重复请求幂等，无法代他人确认。记录及附件写入在同一事务中加锁，防止下发与上传冲突。
4. 个人进度 = 已确认材料数 / 全部材料数；全部确认后一次性计入该课程学时。管理人员看到逐人进度和整体完成率，普通成员只看到本人数据；详情、统计、打印和导出均执行该限制。
5. 所有人完成后，总经办培训进入待审核，可发起企业微信审批；船务学时/案例记录自动关闭。普通成员完成本人任务后移出本人待办，即使他人尚未完成。
6. `GET /workbench/statistics/learning` 返回 `courses` 和 `people`；可选 `month` 按课程发生月份筛选，不传为全部。`GET /workbench/statistics/learning/export` 输出“个人学时 / 学习明细”两张表。

进度依据本人确认，不采集视频播放时长，也不代表考试结果。旧手填完成率不转换为个人已完成；需要重新下发至实际人员。

## 船舶燃油

- `POST /workbench/records/{id}/fuel-actual`：审批通过后，由申请人或管理人员登记/更正 `fuelType`、`unit`（`L` 或 `t`）、`amount`（大于 0，最多三位小数）、`occurredAt`（带时区、非未来）。加注申请数量不计为实际加注。
- `POST /workbench/fuel/measurements`：管理人员或所属船舶船员登记 `vesselId`、`month`、`fuelType`、`unit`、`closingBalance`，可选 `openingBalance`、`lowFuelThreshold`。同船同月同油品同单位只有一条有效测量，并发提交串行更正；省略的期初和阈值保留原值。更正留审计日志。
- 期初优先承接上月月末实测，无上月值时使用首次期初；月耗 = 期初 + 当月实际加注 − 当月月末实测。分油品和计量单位统计，不擅自将吨与升换算。
- 缺期初、缺月末实测、存在待登记的批准申请、或算得负月耗时，返回问题说明；月耗未知时为 `null` 并显示“待核对”，不写成零。余量小于或等于提醒值时显示低余量提示。
- `GET /workbench/statistics/fuel` 返回 `month`、`rows`、`receipts`、`unconfirmed`、`canMeasure`，不传月份时为上海当前月；`GET /workbench/statistics/fuel/export` 输出“燃油月报 / 实际加注明细 / 待登记实绩”。数据范围与当前账号可见记录一致。

本轮完成记录驱动的自动计算、结转与导出。实收和实测仍需登记，未接入油表/传感器，低余量提示显示在页面与报表中，不发送企业微信消息。旧申请缺少船舶关联时需补录正确申请；不从自由文本船名猜测船舶 ID。

## 导出排版

- Excel 使用统一的工作平台报表样式：标题、统计范围、上海生成时间、深蓝表头、斑马纹、缺失数据警示色、冻结窗格、筛选和页脚页码；数字和百分比使用专用格式，文本不解释为公式。
- 考勤 Excel 的逐日表按上半月和下半月分块，每个分块保留日期表头；明细表使用 A3 横向打印。燃油月报使用 A3 横向打印，学习统计使用 A4 纵向打印。
- 考勤 PDF 使用 A4 横向，带摘要卡片、人员汇总、考勤明细、跨页续表和页码；学习记录打印支持 A4/A3，带学习内容、材料和逐人进度表。长文本和长表格会换行或续页，不截断数据。
- 燃油当前提供格式化 Excel 月报和来源明细；页面没有单独的燃油 PDF 导出入口，避免生成与月报字段不一致的第二套格式。

## 错误约定与部署

业务无效数据返回 400，无操作权限返回 403，资源缺失返回 404，学习冻结/审批前登记等状态冲突返回 409。报表的缺失值和待核对提示属于有效响应。

需同时更新 API 与 Web。复用现有 PostgreSQL、文件存储和企业微信配置；本轮代码测试未连接生产、未验证真实企业微信审批或油表接口。手册截图清单见 [2026-09-20 更新清单](../../handbook/2026-09-20-截图更新清单.md)。
