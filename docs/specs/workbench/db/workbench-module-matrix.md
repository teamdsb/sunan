## 2. 模板使用约束

### `ledger_form`
- 必须支持草稿、提交、归档。
- 支持按年度、部门、船舶、会议类型或培训类型过滤。
- 支持资料留存期限字段。

### `operation_flow`
- 必须支持步骤顺序、现场照片、执行人签认、完工确认。
- 同一流程下的步骤状态要可回溯。

### `inspection_rectification`
- 必须支持检查项、是否整改、整改要求、整改前后照片、审核结论。
- 必须支持闭环打印。

### `attendance_statistics`
- 必须区分原始记录与汇总记录。
- 必须定义统一统计口径。

### `service_asset`
- 必须支持资产/设备对象维度检索。
- 必须支持维护保养与使用消耗记录。

### `wecom_approval`
- 必须配置审批模板绑定。
- 审批结论以企业微信实例状态为准。

## 3. 遗留模块补充说明

### 财务板块
- 当前仅能确认其属于财务部门目录下的独立业务承载模块。
- M5 只冻结以下边界：角色范围、业务入口、待确认清单、与统计中心的关系。
- 在原始资料补齐前，不冻结字段级 API、表结构和导出模板。

### 海图更新
- M5 将其明确纳入 `ledger_form` 模板。
- 开发前的最小字段边界限定为：更新批次、适用船舶、版本/日期、说明、附件、确认记录。
- 如后续业务提供更完整台账样例，再补充字段级 SDD。
