# 通知推送规格

## 概述

系统通过企业微信应用消息推送实现主动通知。里程碑1的核心通知场景是证书到期提醒。

详细的消息推送 API 规格见 `docs/specs/wecom/message-push-spec.md`。

## 通知触发场景

| 场景 | 触发时机 | 接收对象 | 优先级 |
|---|---|---|---|
| 证书即将到期 | 每日 09:00 定时扫描 | 相关负责人 | 高 |
| 合同即将到期 | 每日 09:00 定时扫描 | 总经办成员 | 高 |

## 通知路由规则

不同类型证书/合同的通知接收人：

| 对象类型 | 通知接收人 |
|---|---|
| 船舶证书 | 船务部管理员 + 总经办 |
| 车辆证书 | 后勤部负责人 + 总经办 |
| 人员证书 | 当事人 + 所在部门管理员 |
| 人员合同 | 当事人 + 总经办 |
| 服务合同 | 总经办 |

## 通知去重规则

同一证书同一到期提醒周期内，如已发送且对方已确认（`status = acknowledged`），不再重复推送。如未确认，每天重复提醒。
