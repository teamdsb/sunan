# 工作平台企业微信上线检查清单（M4）

## 1. 文档定位

本清单用于 M4 工作平台正式上线前的专项检查，覆盖企业微信 H5、审批桥、消息推送、回调、JS-SDK 与真机联调。

## 2. 应用与基础配置

- [ ] 企业微信自建应用已创建并确认 `AgentId`。
- [ ] H5 访问域名已配置为可信域名。
- [ ] 可信域名已完成备案与归属验证。
- [ ] OAuth2 回调地址已配置并与生产地址一致。
- [ ] 应用可见范围已覆盖总经办、财务部、业务部、船务部、后勤部及工作组。
- [ ] 系统管理员与各部门管理员企业微信身份已加入可见范围。

## 3. 身份认证与 JS-SDK

- [ ] OAuth2 回调可正确获取用户身份并创建系统 JWT。
- [ ] 企业微信 iOS 使用首次加载 URL 签名验证通过。
- [ ] 企业微信 Android 使用当前 URL 签名验证通过。
- [ ] JS-SDK 依赖的 `jsapi_ticket` 缓存可正常刷新。
- [ ] 拍照、图片上传、文件预览能力在真机上可正常调用。

## 4. 企业微信审批桥

- [ ] 审批模板已在企业微信后台创建并登记模板编码。
- [ ] `moduleCode -> templateCode -> wecomTemplateId` 映射已配置。
- [ ] 审批发起接口能正确创建审批实例。
- [ ] 审批回调地址已启用并完成验签配置。
- [ ] 审批回调能正确落镜像状态与审计日志。
- [ ] 审批对账任务已配置告警与重试策略。
- [ ] 审批完成、拒绝、撤销、终止场景均完成联调。

## 5. 应用消息

- [ ] 工作平台待办提醒已配置应用消息模板。
- [ ] 审批类模块待审批提醒已验证。
- [ ] 审批完成通知已验证。
- [ ] 重复消息、超频消息与无权限成员消息场景已验证。
- [ ] 消息接收人与应用可见范围一致。

## 6. 工作平台专项检查

- [ ] 模块入口按角色正确显示。
- [ ] 台账类模块打印与资料留存可用。
- [ ] 作业闭环类模块现场图片上传、步骤推进与完工确认可用。
- [ ] 检查整改类模块整改前后照片、审核结论与归档可用。
- [ ] 统计类模块月度汇总、导出和口径一致性可用。
- [ ] 资产服务类模块维修/保养/油耗与月报可用。

## 7. 真机联调

- [ ] 企业微信 iOS 端完成首页、列表、详情、附件、审批、打印全流程测试。
- [ ] 企业微信 Android 端完成首页、列表、详情、附件、审批、打印全流程测试。
- [ ] 弱网下图片上传与审批提交体验可接受。
- [ ] 长表单返回、重进、重复点击和会话过期处理已验证。

## 8. 可观测与应急

- [ ] 审批回调失败可告警。
- [ ] 消息发送失败可告警。
- [ ] JS-SDK 签名失败可排障。
- [ ] 审批实例和业务单据支持按 ID 检索。
- [ ] 关键接口已纳入日志与追踪。
- [ ] 上线回滚预案与停用开关已准备。
