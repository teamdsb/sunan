# 企业微信上线检查清单（M6）

## 1. 文档定位

本清单用于 M6 正式上线前的专项检查，覆盖四大板块、企业微信 H5、审批桥、消息推送、回调、JS-SDK、真机联调、异常运维和上线材料。

最近一次执行记录：
- [go-live-preflight-2026-04-22.md](/Users/yuan/项目/sunan/sunan/docs/specs/wecom/go-live-preflight-2026-04-22.md)

## 2. 应用与基础配置

- [ ] 企业微信自建应用已创建并确认 `AgentId`
- [ ] `WEB_PUBLIC_URL` 与企业微信工作台首页地址一致
- [ ] H5 访问域名已配置为可信域名
- [ ] JS 接口安全域名与前端正式域名一致
- [ ] OAuth2 回调地址已配置并与 `WECOM_REDIRECT_URI` 一致
- [ ] 事件接收服务器 URL 已配置并指向 `API_PUBLIC_URL`
- [ ] `WECOM_CALLBACK_TOKEN` 与后台 Token 一致
- [ ] 如启用加密回调：`WECOM_ENCODING_AES_KEY` 与后台一致
- [ ] 应用可见范围已覆盖四大板块目标成员
- [ ] 系统管理员与各部门管理员已加入可见范围

## 3. 身份认证与 JS-SDK

- [ ] OAuth2 回调可正确获取用户身份并创建系统 JWT
- [ ] 企业微信 iOS 使用首次加载 URL 签名验证通过
- [ ] 企业微信 Android 使用当前 URL 签名验证通过
- [ ] `jsapi_ticket` 缓存可正常刷新
- [ ] 拍照、图片上传、文件预览能力在真机上可正常调用
- [ ] JS-SDK 签名失败时可通过日志与错误码快速排障

## 4. 审批桥与回调安全

- [ ] 审批模板已在企业微信后台创建并登记模板编码
- [ ] 模板绑定清单已更新
- [ ] 审批发起接口能正确创建审批实例
- [ ] 回调地址已启用并完成验签配置
- [ ] 来源 IP 校验已启用并验证
- [ ] 若启用加密回调：解密流程已验证
- [ ] 回调能正确落镜像状态与审计日志
- [ ] 对账任务已配置告警与重试策略
- [ ] 审批完成、拒绝、撤销、终止场景均完成联调
- [ ] 管理员异常检索、单实例重试、批量对账接口已验证

## 5. 应用消息

- [ ] 工作平台待办提醒已配置应用消息模板
- [ ] 采购审批提醒已验证
- [ ] 证照/提醒消息已验证
- [ ] 审批完成通知已验证
- [ ] 重复消息、超频消息与无权限成员消息场景已验证
- [ ] 消息发送失败有告警或留痕记录

## 6. 四大板块专项检查

- [ ] `我的`：证照、提醒、监控、设置链路可用
- [ ] `办事`：入口可见性、打开行为与治理审计可用
- [ ] `采购管理`：录单、审批、报表、打印、消息可用
- [ ] `工作平台`：模块入口、录单、详情、附件、审批、打印、导出可用
- [ ] 工作平台运行态已持久化，不再依赖内存状态
- [ ] `海图更新` 模块可录单并留存资料
- [ ] `财务板块` 若未补料，不在正式菜单中暴露

## 7. 真机联调与留痕

- [ ] 企业微信 iOS 端完成四大板块核心链路测试
- [ ] 企业微信 Android 端完成四大板块核心链路测试
- [ ] 弱网下图片上传、审批提交和导出体验可接受
- [ ] 长表单返回、重进、重复点击和会话过期处理已验证
- [ ] 每条关键链路均保留截图或录屏证据
- [ ] 每条证据均标注设备型号、系统版本、企业微信版本、执行人、执行时间

## 8. 可观测与应急

- [ ] OAuth2 登录失败可排障
- [ ] 审批回调失败可告警
- [ ] 消息发送失败可告警
- [ ] JS-SDK 签名失败可排障
- [ ] 审批实例和业务单据支持按 ID 检索
- [ ] 关键接口已纳入日志与追踪
- [ ] 导出任务失败可追踪
- [ ] 上线回滚预案与停用开关已准备
- [ ] 值班人与联系人清单已确认
