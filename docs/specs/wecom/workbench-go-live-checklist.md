# 工作平台企业微信上线检查清单（M6）

## 1. 文档定位

本清单用于 M6 正式发布前的最终核对，覆盖：

- 生产参数
- OAuth2 / JS-SDK
- 审批模板与消息模板
- 回调配置
- 真机证据
- UAT
- 回滚与值班

## 2. 应用与域名

- [ ] 企业微信自建应用已创建并确认 `AgentId`
- [ ] 工作台首页地址指向生产 HTTPS 域名
- [ ] 可信域名已精确配置到实际访问域名
- [ ] OAuth2 回调域名已配置并与生产地址一致
- [ ] JS 接口安全域名已配置
- [ ] 应用可见范围覆盖总经办、财务部、业务部、船务部、后勤部、工作组与系统管理员

## 3. OAuth2 与身份

- [ ] OAuth2 回调可正确获取用户身份并签发系统 JWT
- [ ] `redirect_uri` 与企业微信后台登记一致
- [ ] `state` 校验已验证
- [ ] 会话过期后的重新拉起链路已验证

## 4. JS-SDK

- [ ] M6 目标接入方式已冻结为 `@wecom/jssdk` / `ww.register`
- [ ] legacy adapter 范围、回退条件和恢复计划已记录
- [ ] iOS 使用首次加载 URL 签名验证通过
- [ ] Android 使用当前页面 URL 签名验证通过
- [ ] 拍照、图片上传、文件预览在真机上均可用
- [ ] JS-SDK 失败事件可进入管理员诊断视图

## 5. 审批模板与审批桥

- [ ] 审批模板已在企业微信后台创建并登记模板编码
- [ ] `moduleCode -> templateCode -> wecomTemplateId` 映射已冻结
- [ ] 审批模板负责人已明确
- [ ] 审批发起接口验证通过
- [ ] 审批回调地址、`Token`、`EncodingAESKey` 已配置并验证通过
- [ ] 审批回调可正确落镜像状态与审计日志
- [ ] 审批异常检索、单实例重试、批量对账已验证

## 6. 消息模板与消息链路

- [ ] 待办提醒模板已冻结
- [ ] 审批完成通知模板已冻结
- [ ] 模板负责人已明确
- [ ] 目标接收人规则与应用可见范围一致
- [ ] 消息失败留痕与告警策略已验证

## 7. 工作平台专项

- [ ] 模块入口按角色正确显示
- [ ] 独立模块页路由可访问
- [ ] Batch A 模块的列表、详情、动作、附件、打印、归档可用
- [ ] Batch B 模块的审批、对账、导出、状态镜像可用
- [ ] 工作平台运行时持久化可用，不依赖内存态
- [ ] 管理员控制台的 approvals / exports / reconcile / diagnostics 路由可访问

## 8. 真机回归与证据

- [ ] iOS 企业微信全链路回归完成
- [ ] Android 企业微信全链路回归完成
- [ ] 每条关键链路均保留截图或录屏
- [ ] 每份证据标注设备型号、系统版本、企业微信版本、执行人、执行时间
- [ ] JS-SDK、上传、审批、导出、打印、管理员诊断均有真机证据
- [ ] 如发生 legacy 回退，已附回退条件、模块范围、恢复计划证据

## 9. UAT 与缺陷闭环

- [ ] 各部门至少完成 1 组模块 UAT 样例确认
- [ ] 字段、流程、打印、统计、权限均经业务确认
- [ ] P0 缺陷全部关闭
- [ ] P1 缺陷均有关闭结论或发布前规避方案
- [ ] 缺陷清单、证据和复测结果齐备
