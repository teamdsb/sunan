# 工作平台上线材料与应急 Runbook（M6 Wave7）

## 1. 文档定位

本 Runbook 用于冻结 Wave7 的上线材料包、回滚预案和值班机制，作为正式发布窗口执行手册。

## 2. 上线材料包清单

发布前必须齐备以下材料：

- 企业微信后台配置截图（应用、可信域名、回调、模板）
- 审批模板映射清单（`moduleCode -> templateCode -> wecomTemplateId`）
- 消息模板清单与负责人
- OpenAPI 校验结果
- 模块级测试矩阵执行结果
- 路由级测试矩阵执行结果
- 真机回归结果与证据目录
- UAT 表单与业务签字结论
- 缺陷闭环汇总（P0/P1/P2）
- 发布窗口操作手册

## 3. 发布前 Gate

- Gate A：规格 Gate
  - OpenAPI 全量校验通过
  - Wave7 测试矩阵与模板已冻结
- Gate B：质量 Gate
  - P0 = 0
  - P1 全部有关闭结论或发布规避结论
- Gate C：运行时 Gate
  - 审批回调、消息回调、JS-SDK 真机链路通过
  - 管理员诊断页可检索发布前演练事件

## 4. 回滚触发条件

满足任一条件立即执行回滚：

- 出现 P0 线上故障且 15 分钟内无法止损
- OAuth2 登录或审批回写主链路不可用
- 导出/对账任务出现持续失败并影响核心业务
- JS-SDK 大面积初始化失败且无可行降级路径

## 5. 回滚流程

1. 发布负责人宣布进入回滚。
2. 前端回退到上一稳定静态版本。
3. 后端切回上一稳定镜像版本。
4. 若本次发布含迁移，按迁移回滚脚本执行数据库回退或数据修复。
5. 触发全链路冒烟：登录、审批、导出、诊断。
6. 完成回滚结论与影响通报。

## 7. 发布后 24 小时观察

- 每 2 小时抽检：登录、审批回写、消息推送、管理员诊断
- 汇总异常事件数量与处置结论
- 观察期结束输出“发布稳定性结论”
