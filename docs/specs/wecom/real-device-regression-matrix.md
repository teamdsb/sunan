# 企业微信四大板块真机回归矩阵（M6）

## 1. 文档定位

本矩阵用于 M6 Wave 3 `WS-3C` 验收，统一覆盖企业微信容器下“我的 / 办事 / 采购管理 / 工作平台”四大板块，并作为上线材料的标准证据索引。

## 2. 设备与执行信息

| 字段 | 要求 |
|---|---|
| 平台 | iOS 企业微信 / Android 企业微信 |
| 设备型号 | 必填 |
| 系统版本 | 必填 |
| 企业微信版本 | 必填 |
| 执行环境 | 预发布 / 生产 |
| 执行人 | 必填 |
| 执行时间 | 必填 |

## 4. 失败分级与处理

- P0：登录、审批主链路、核心录单不可用，阻断上线。
- P1：关键功能可用但存在明显业务风险，需修复或给出规避方案。
- P2：体验问题，不阻断上线但需纳入后续修复。

## 5. 证据命名

- 建议格式：`{date}_{board}_{case}_{platform}_{executor}`。
- 每条关键链路至少保留 1 份截图或录屏。
- 证据必须能追溯到设备信息、企业微信版本和执行时间。
