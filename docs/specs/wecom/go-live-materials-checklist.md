# 企业微信上线材料清单（M6）

## 必备材料

- [ ] 真机回归结果表
- [ ] 截图/录屏证据目录
- [ ] 缺陷清单与闭环状态
- [ ] 企业微信后台配置截图
- [ ] 审批模板绑定清单
- [ ] 发布单与发布时间窗口
- [ ] 回滚预案与联系人清单
- [ ] 值班人与告警项说明
- [ ] 生产环境变量核对表
- [ ] 数据库备份与恢复演练记录

## 归档要求

- 材料按 `wave / date / owner` 归档。
- 截图或录屏文件名统一包含日期、平台、场景、执行人。
- 版本号、企业微信版本、设备型号必须可追溯。

## 材料责任分工

| 材料 | 责任角色 |
|---|---|
| 真机回归结果表 | 测试负责人 |
| 缺陷清单与闭环状态 | 测试负责人 + 研发负责人 |
| 企业微信后台配置截图 | 企业微信管理员 |
| 审批模板绑定清单 | 业务管理员 + 后端负责人 |
| 发布单与发布时间窗口 | 发布负责人 |
| 回滚预案与联系人清单 | 运维负责人 |
| 告警项说明 | 后端负责人 |
| 环境变量核对表 | 后端负责人 |
| 备份恢复演练记录 | DBA |
