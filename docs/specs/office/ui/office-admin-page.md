# 办事治理台页面规格

## 目标

为分类维护人和系统管理员提供入口治理能力。

## 页面组成

- 过滤栏
- 入口表格
- 新建/编辑表单抽屉
- 发布/停用操作区
- 审计记录区（最近操作、按动作和入口过滤）
- 权限受限提示

## 交互规则

- 仅具备分类维护权的用户可进入。
- 表单需校验目标类型、URL/路由、可见角色与管理角色。
- 发布和停用使用显式操作按钮，不在表单提交时隐式变更状态。
- 审计记录按时间倒序展示，至少包含：动作、入口、操作人、时间。
