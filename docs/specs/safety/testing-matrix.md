# M8 测试与验收矩阵

## Wave 1 文档门禁

| 工作包 | 必须证据 | 通过规则 |
|---|---|---|
| M8-W1A | 需求、路线图、执行计划、backlog、代码差距基线的路径/接口/测试证据 | 领域边界和现状判断无互相矛盾的结论 |
| M8-W1B | `domain-boundaries.md`、`terminology-and-status.md`、四个规格目录索引 | 术语、状态、非目标和后续规格入口唯一且可解析 |
| M8-W1C | 本矩阵、`migration-principles.md`、验收模板、提示词索引 | 文档清单/索引/格式检查和人工扫描均通过 |

Wave 1 不运行或宣称业务功能测试通过；它只验证文档基线与未新增业务代码的范围。

## 后续 Wave 的最小测试层次

| 测试层次 | 适用 Wave | 最小覆盖 | 证据形式 |
|---|---|---|---|
| 单元测试 | 2-6 | 权限判定、状态转换、幂等键、期限与时区规则 | API 服务或领域服务测试 |
| PostgreSQL 集成测试 | 2-7 | migration、外键、索引、软删除、允许/拒绝权限矩阵与事务回滚 | migration 驱动的 testcontainers 记录 |
| API 合约测试 | 2-6 | 每个 OpenAPI 路径的成功、400、401、403、404、409/422 响应 | `swagger-cli validate` 与 API 集成测试 |
| 前端组件/页面测试 | 2-6 | 加载、空态、错误、权限不足、重复提交、移动交互 | React Testing Library 或等效测试 |
| 异步与补偿测试 | 3、5、6 | 导出、提醒、自动建任务/问题的去重、重试、失败补偿与审计 | job/service 集成测试 |
| 迁移演练 | 4、7 | 映射、重复执行、对账、只读兼容与回滚 | 演练报告和 SQL/脚本输出 |
| 企业微信真机回归 | 3、5、6、7 | 工作台/消息深链、拍照、定位、签名、弱网恢复 | iOS、Android、桌面端截图或录屏索引 |

## 安全主链路覆盖

| 风险 | 最低场景 | Wave |
|---|---|---|
| 越权读取或推进 | 船员跨船、非参与人、管理员敏感查看 | 2、7 |
| 参与人隔离 | 执行人、审核人、验证人冲突与代理失效 | 2、6 |
| 证据完整性 | 绑定、预览、下载、解除关联、替换、审计和文件复用 | 3、7 |
| 任务重复 | 重放计划生成、并发创建、消息重试 | 5、7 |
| 检查与 CAPA | 多人完成、自动转单、返工、验证失败、关闭拦截 | 6、7 |
| 数据正确性 | 主数据停用、历史引用、迁移对账、回滚 | 4、7 |

所有集成测试必须使用 PostgreSQL testcontainers，不使用 SQLite 模拟；所有真机结论必须区分“已验证”和“未执行”，不得用模拟模式替代。
