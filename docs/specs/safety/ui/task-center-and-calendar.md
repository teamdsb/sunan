# Wave 5 任务中心、计划与日历页面规格

## 路由与信息结构

安全任务在既有工作平台内呈现，使用路由级懒加载：`/workbench/tasks`（任务中心）、`/workbench/tasks/:taskId`（任务详情/企业微信深链）、`/workbench/plans`（计划管理）与 `/workbench/plans/:planId`（计划及计划项）。不新增第五个一级导航、不预加载任务中心到无关企业微信入口。

任务中心采用用户确认的 A 布局：顶部数据范围标签固定为“待办、我发起、我参与、已完成、逾期”，标签对应同一 `GET /tasks` 的 `view` 参数；下面的“列表 / 日历”仅切换渲染方式，并继承范围、船舶、计划、状态和日期筛选。移动端默认列表；桌面可并排月历和选中日期列表。不得保留、渲染或回退到静态排程、模拟任务或独立日历数据源。

## 页面规则

- 计划列表：显示状态、负责人、范围、下一次发生、任务完成率和异常生成运行；负责人可创建草稿、编辑、启用、暂停或退役，管理员可跨范围操作。
- 计划详情：计划项以标题、责任人、参与人、规则、期限、版本、启用状态和真实生成摘要呈现；规则更新说明“只影响未来任务”，历史任务通过详情链接查看。
- 待办：只显示当前用户下一步可执行的未终态任务。已转移、代理失效或无可执行权限的任务不得留在待办中。
- 我发起：按任务发起/计划负责人范围返回；我参与：按活跃或历史参与关系返回，历史转移任务显示交接标识但不显示执行按钮；已完成和逾期均由服务端派生过滤。
- 日历：用同一任务数组在客户端按计划时区日期分组。日期格显示真实任务数量和状态色；点击日期打开任务清单。逾期为红色风险标识，不把它写成独立任务状态；月切换只改变 `startAt/endAt`。
- 任务详情：展示状态、计划来源、发生/期限、负责人、参与人、范围快照、完成条件、动作轨迹、改期/取消/转移原因和投递状态。可执行动作只来自 `availableActions`；403 不显示任务名称、期限、人员或消息元数据。
- 消息直达：首次打开深链先等待认证恢复，再按任务 ID 查询；404 显示资源不存在，403 显示无权访问，均不泄露摘要。返回路径使用本地安全 `backTo` 规则。

## 操作、反馈与移动端

改期、取消、转移、代理、催办和升级均使用确认抽屉或弹窗：危险动作展示影响说明，必须填写原因，提交中禁用重复点击，成功后失效同一任务、列表、日历和计划查询缓存。转移明确说明“原责任人将不能继续执行，历史轨迹保留”；取消说明不会删除历史；催办/升级显示最近投递和去重提示。

加载显示业务骨架；无任务显示范围对应的空态；生成/投递失败显示可理解原因和授权重试入口；401 提供认证恢复；弱网保留表单值并提示重试。320px 起保持单列、无页面横向滚动、操作热区至少 44px；沿用现有蓝白企业 H5、标题层级和轻量卡片风格，不替换系统视觉语言。
