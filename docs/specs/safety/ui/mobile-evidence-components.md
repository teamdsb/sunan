# Wave 3 移动证据组件规格

## `EvidencePanel`

工作平台详情和采购单详情共用展示、上传、拍照、预览、下载和解除确认模式；领域适配器提供 URL、授权结果和解除关联动作。普通用户不输入 fileId：文件选择/企业微信拍照成功后由组件内部获得 fileId 并调用绑定接口。

- 文件：可多选、上传进度、失败重试、文件名/类型/大小、预览与下载。
- 拍照：仅 JS-SDK ready 后可用，调用 `chooseImage`、`uploadImage` 和转存接口；配置失败、取消、版本不支持均提示重试初始化或使用“选择文件”。
- 签名：Canvas 清空/确认，确认后上传签名图并提交摘要哈希；未签名不能提交。
- 定位：显示采集、重新授权和失败说明；拒绝/SDK 失败不展示或合成坐标，允许填写人工异常说明。
- 解除：危险操作必须二次确认、要求原因、说明“仅解除当前业务关联，不删除原文件”；成功后刷新详情，失败保留可恢复反馈。

## 权限与移动体验

只有服务端返回可用操作时才显示上传、解除、签名、定位或重试。403 不显示文件名、摘要或下载 URL。操作热区至少 44px；直达目标详情时等待认证恢复；弱网保留上传失败项并提供重试，导出 queued/running 显示状态而非假下载按钮。

## 真机验收记录

分别记录 iOS/Android：设备型号、系统版本、企业微信版本、工作台直达 URL、拍照转存、定位成功/拒绝恢复、签名、预览和下载结果，以及截图或录屏文件索引。开发环境未连接真机时，验收文档必须标记为待执行而不是通过。
