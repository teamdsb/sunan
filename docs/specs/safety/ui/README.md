# 安全领域 UI 规格目录

本目录冻结页面与组件规格入口，不创建未评审页面或路由。安全能力在“工作平台”及企业微信深链中呈现，不新增第五个一级导航或小程序。每份 UI 规格必须遵循 `../../common/frontend-experience-guidelines.md`，覆盖直达、认证恢复、320px 移动端、加载、空态、错误、权限不足、弱网和重复提交。

| Wave | 预期文件 | 范围 |
|---|---|---|
| 2 | `permission-and-action-rules.md` | 受权数据、可执行动作和拒绝反馈 |
| 3 | `mobile-evidence-components.md` | 已冻结：附件、拍照、签名、定位、解除关联和导出反馈 |
| 4 | `master-data-pages.md` | 主数据列表、详情、选择器、导入和停用提示 |
| 5 | `task-center-and-calendar.md` | 待办、我发起、我参与、任务详情与日历 |
| 6 | `inspection-and-capa-pages.md` | 已冻结：检查执行、问题、措施、验证、关闭与来源回链 |

路由、页面、组件和设计稿均须在相应 UI 规格评审后创建。
