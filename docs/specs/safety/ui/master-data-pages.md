# M8 Wave 4 主数据页面与选择器规格

证书对象在“我的”模块下以独立同级入口 `/my/master-data` 提供，导航位置固定在“证书提醒”下方；从企业微信工作台进入时仍支持 `/workbench/master-data` 直达。页面以船舶、车辆、人员、设备四个标签页展示，所有页面支持移动端单列和直接打开。

- 船舶 360：基本信息、有效证书、当前/历史任职、设备、文本引用映射；停用状态明确标识。
- 人员：企业微信绑定、任职历史、证书；本人、系统管理员或有船务管理范围者才显示手机号和 WeCom UserId，其余显示脱敏或不显示。
- 设备：编码、分类、所属船舶、状态、证书；停用/报废不可在新建业务中选用。
- 导入：显示批次摘要（新增、更新、跳过、失败）、失败行和下载入口；重复上传同内容显示既有批次，不重复提交。
- 选择器：输入名称或编码搜索，默认只显示 `active` 且当前用户有权的对象；禁止展示或要求输入 UUID。历史详情显示关联时的 `displaySnapshot` 和停用徽标，不复用新建选择器。

各页必须有加载、空态、网络错误、无权限、弱网重试和重复提交禁用状态。停用动作显示“历史记录仍保留显示、不能用于新业务”的二次确认。
