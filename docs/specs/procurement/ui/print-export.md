# 打印与导出规格

## 输出类型

- 采购单 A4 PDF
- 报表审批单 A4 PDF

## 实现约束

1. 后端统一生成 PDF，保证企业微信 iOS/Android 一致性。
2. 模板分离：采购单模板与报表模板不复用。
3. 导出文件保存到 OSS，返回 fileId 与下载链接。
4. 导出内容固定使用提交/审批时快照，避免二次查询口径漂移。
5. “预览 PDF”和“导出 PDF”是两个独立动作：预览在后端生成完成后直接打开应用内弹窗，导出触发浏览器文件下载。
6. 禁止在异步生成完成后调用 `window.open`，避免被浏览器拦截或产生空白窗口。
7. 同一报表业务状态未变化时复用最近一次有效导出；提交、审批或退回产生新状态后必须重新生成，避免预览后下载重复执行字体嵌入和 OSS 上传。

## 附件交互

- 采购附件上传前展示允许格式和 20MB 单文件限制。
- 已绑定附件通过采购单记录级下载接口获取短期 URL。
- PDF、图片、HEIC、TXT、CSV 使用统一预览弹窗；Office、WPS 与压缩包展示文件信息并提供下载。

## 版式要求

- 中文字体必须可靠嵌入，并用系统预览或 Poppler 完成真实渲染检查；不得出现缺字、方框或错位字形。
- 采购单和报表审批单分别使用独立 A4 模板；报表模板不得回退为快照 JSON 或纯文本行列表。
- 报表审批单依次包含业务标题、状态条、指标摘要、统计条件、其他参数、汇总明细、审批记录和数据快照说明。
- 金额字段右对齐，统一为人民币千分位和两位小数；采购单数、维度数使用业务单位。
- 多页表格自动分页，续页重复页眉、分区标题和表头；表格行不得覆盖页脚。
- 每页页眉包含平台、报表标题和报表号；页脚包含生成时间与“当前页 / 总页数”。
- 报表只使用审批提交时的参数和汇总快照，审批记录按审批时间升序输出。
