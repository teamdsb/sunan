# 采购单列表页规格

## 页面目标

支持按条件筛选和浏览采购单，覆盖近 3 年范围查询。

## 年度预算卡片

- 从预算汇总 API 读取当前年度数据，禁止静态兜底。
- 预算总额和已执行金额均大于 `0` 时显示。
- 已执行只统计终审通过且费用日期属于目标年度的采购单。
- 超预算显示真实比例、红色进度环和红色超出金额。
- 卡片隐藏时，采购流程和供应商区域自动铺满。

## 筛选项

- 关键词（标题/摘要）
- 部门
- 细分类型/细分对象
- 状态
- 时间范围（默认近3年）

## 列表字段

- 单号
- 部门
- 细分对象
- 标题
- 金额
- 当前状态
- 提交时间
- 最后更新时间

## 操作

- 查看详情
- 新建采购单
- 草稿继续编辑
- 已终审单打印
