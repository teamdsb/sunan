# 采购录单页规格

## 页面目标

完成采购单草稿创建、编辑、附件上传与提交。

## 表单字段

- 部门（必填）
- 细分类型（自动联动：仅船舶部/后勤部可选）
- 细分对象（条件必填）
- 标题（必填）
- 摘要/事由（必填）
- 金额（必填，保留2位小数）
- 费用日期（可选）
- 附件（可多选）

## 交互规则

1. 非船舶部/后勤部时，细分字段隐藏并写入 `dimension_type=none`。
2. 可保存草稿，不触发审批。
3. 提交后进入 `submitted`，页面转只读。
4. 被退回后允许编辑并“重新提交”。

## 错误态

- 金额格式错误
- 必填字段缺失
- 附件绑定失败
- 提交失败（权限或状态冲突）
