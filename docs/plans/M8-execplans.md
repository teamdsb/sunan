## 2. 执行原则

1. M8 专业领域必须复用 M7 权限、任务、证据和 CAPA。
2. 高风险作业必须使用专用聚合流程和结构化检查表。
3. 设备修理和备件采购复用采购管理，不复制审批。
4. 外部监管事项只记录人工上报，不接外部接口。
5. 每个自动化联动必须有幂等、补偿、对账和审计。
6. 每个 Wave 的前置数据质量必须可测量。

## 3. Wave 1：M8 规格冻结与 M7 基线回归

### 目标

- 证明 M7 底座足以支撑 M8。
- 冻结专业领域对象、状态和跨域关系。
- 阻断未关闭 P0 缺陷和不完整主数据。

### 实现范围

- 回归权限、任务、证据、CAPA、导出和真机链路。
- 建立人员、作业、应急、设备、治理、文件内审规格组。
- 建立资格快照、采购来源关联和人工监管登记规则。
- 建立数据迁移、验收和回滚矩阵。

### 验收标准

- M7 回归门禁通过。
- 专业对象无重复或互相冲突的状态机。
- 每个后续 Wave 明确复用的 M7 API 和数据对象。
- 无外部接口或小程序范围漂移。

## 4. Wave 2：人员安全与培训资格

### 前置

- Wave 1 通过。
- 人员安全规格已评审。

### 实现范围

- 船员任职、调配、上下船和交接。
- 证书、健康、岗位和任职资格判断。
- 未结任务、问题和设备责任的交接转移。
- 培训需求池、计划、签到、学习、考试、补考和评价。
- 熟悉职责清单、岗位签认和完成门槛。
- 航次或上岗资格快照。

### 验收标准

- 资格失效、健康过期和熟悉未完成可阻断指定业务。
- 调配和交接不会丢失未结任务。
- 多人培训保留个人完成和考试结果。
- 历史资格判断可通过快照复原。

## 5. Wave 3：航次与船舶高风险作业

### 前置

- Wave 2 通过。
- 作业许可规格已评审。

### 实现范围

- 航次校验人员、证书、重大问题和开航检查。
- 燃油审批通过后幂等生成供受油检查任务。
- 有限空间包含许可、气体检测、监护和人员进出。
- 明火包含消防措施、监护和结束复查。
- 危险货物和高空舷外包含专用风险检查。
- 环保作业记录数量、接收单位和单证。
- 值守巡查、交接、漏检提醒和海图版本核验。

### 验收标准

- 前置条件不满足时不可绕过发起或许可。
- 每类高风险作业都有必需证据和签名。
- 自动生成任务不重复。
- 作业发现问题可进入 CAPA。

## 6. Wave 4：应急、事故险情与防台

### 前置

- Wave 3 通过。
- 应急和事故规格已评审。

### 实现范围

- 年度计划生成船舶、岸基和联合训练演习任务。
- 演习脚本、角色、过程、证据和评价。
- 评价改进项进入任务或 CAPA。
- 应急事件启动、指挥、日志、审阅和结案。
- 事故险情快报、调查、原因、损失、责任和措施。
- 防台预警、会议、检查、部署、动态报备、解除和小结。

### 验收标准

- 计划与实施评价可双向追踪。
- 事故结案前必须完成调查和措施。
- 防台任务按船舶和阶段聚合。
- 人工上报状态明确标注来源。

## 7. Wave 5：设备维护、修理、备件与采购

### 前置

- Wave 4 通过。
- 设备和库存规格已评审。

### 实现范围

- 船舶设备树、分类、参数和周期模板。
- 年度计划自动拆分月度维护任务。
- 多人执行、船长确认和岸基审查。
- 缺陷关联设备、检查、修理、采购和验收。
- 厂修项目、报价、进度和结项。
- 备件字典、库存流水、申领、发放、领用、退库和盘点。
- 采购审批、到货和金额回写来源需求。

### 验收标准

- 周期任务不重复生成。
- 库存并发安全且不允许无授权负库存。
- 缺陷在验收前不能关闭。
- 采购单与技术需求双向可追踪。

## 8. Wave 6：安全责任、费用与管理复查

### 前置

- Wave 5 通过。
- 安全治理规格已评审。

### 实现范围

- 安全责任模板、年度签订、签名和履职检查。
- 安全费用预算、类别、使用登记和采购占用。
- 指定人员周期计划、多人检查和问题转单。
- 船长复查清单、会议、报告和岸基审阅。
- 管理评审输入、决议、行动项和有效性评价。

### 验收标准

- 责任书签署身份和版本可追溯。
- 安全费用不重复记账，采购取消可释放占用。
- 监督和复查问题统一进入 CAPA。
- 管理评审行动项进入统一任务。

## 9. Wave 7：受控文件、内审、统计与档案

### 前置

- Wave 6 通过。
- 文件、内审、报表和档案规格已评审。

### 实现范围

- 内部文件变更、审批、版本、替换和修订说明。
- 外来文件适用性评审和更新。
- 分发、阅读确认、水印和撤回。
- 内审计划、审核组、首末次会议、审核方案和个人底稿。
- 汇总、不符合项、船舶报告、公司总报告和分发。
- 全域统计和异步导出。
- 人工监管上报事项和回执归档。
- 档案保管期限、冻结、借阅和访问审计。

### 验收标准

- 受控文件现行版本唯一。
- 未确认阅读可催办和统计。
- 内审发现自动进入 CAPA。
- 报告数据可追溯到审核记录。
- 人工监管记录不会显示为外部接口同步。

## 10. Wave 8：全域联调、上线与验收

### 前置

- Wave 1-7 通过。
- 无未关闭 P0 缺陷。

### 实现范围

- 跨人员、航次、作业、应急、设备、采购、文件、内审和 CAPA 联调。
- 数据迁移、质量核查、回滚和恢复演练。
- 权限、安全、性能、弱网、真机和打印导出测试。
- 更新操作手册、截图清单、培训材料和上线 runbook。
- 建立 M8 上线包和 Hypercare。

### 验收标准

- 核心专业链路全部有真机证据。
- 全量测试、构建和 OpenAPI 校验通过。
- 迁移、回滚和恢复记录可审计。
- 操作手册与生产页面一致。
- M8 结束后对平台对比报告重新评级。
