# M8 Wave 3 提示词：航次与船舶高风险作业

```text
执行 M8 Wave 3，将航次、燃油和主要高风险作业从通用记录升级为专用许可与检查闭环。

前置：Wave 2 人员资格已验收。

必须阅读：
- AGENTS.md
- docs/requirements/M8-专业安全业务深化与体系完善.md
- docs/plans/M8-execplans.md
- docs/plans/M8-wave-backlog.md
- ship-operation 规格组
- M7 任务、证据、检查和 CAPA 规格
- M8 personnel-safety 资格快照规格
- 现有航次、燃油、有限空间、油污水、海图和作业流程规格与代码

按 SDD/TDD 完成：
1. 先评审 ship-operation API/DB/state/UI 规格和各作业检查表。
2. 先写前置阻断、重复自动派单、必需证据和非法关闭测试。
3. 航次校验人员资格、船舶证书、开航检查和未关闭重大问题，并保存快照。
4. 燃油审批通过后幂等生成供受油检查任务，结果回写来源。
5. 有限空间实现许可、气体检测、监护、人员进出和结束确认。
6. 明火实现消防条件、监护和结束复查。
7. 危险货物和高空舷外实现各自专用风险检查。
8. 完善岸电、油污水、垃圾、生活污水单证，值守巡查交接和海图版本核验。

硬性验收：
- 前置条件不满足时不能通过修改前端绕过。
- 每类高风险作业有明确执行人、许可人、监护人和关闭人。
- 必需的检测、签名、照片缺失时不能关闭。
- 自动派单重复回调不重复建单。
- 发现的问题可进入 CAPA 并双向追踪。

不接外部设备或监管接口。

验证：
- 运行完整受影响测试、API/Web build、OpenAPI、migration、文档校验和企业微信移动端关键作业回归。

最终报告：
- 附航次资格阻断、各类作业许可、必需证据、自动派单和 CAPA 关联证据。
```
