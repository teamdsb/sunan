# M8 Wave 4 提示词：应急、事故险情与防台

```text
执行 M8 Wave 4，建设应急计划、训练演习、应急事件、事故险情调查和防台全过程。

前置：Wave 3 通过。

必须阅读：
- AGENTS.md
- docs/requirements/M8-专业安全业务深化与体系完善.md
- docs/plans/M8-execplans.md
- docs/plans/M8-wave-backlog.md
- emergency-incident 规格组
- M7 计划任务、证据和 CAPA 规格
- 现有演练、培训、会议和检查模块规格

按 SDD/TDD 完成：
1. 冻结应急、事故和防台的状态、权限、证据和结案规则。
2. 先写计划生成、评价转任务/CAPA、事故结案门槛和防台阶段测试。
3. 年度计划生成船舶、岸基和船岸联合训练演习任务。
4. 演习记录脚本、角色、过程、通信、照片、签名和评价。
5. 评价问题生成改进任务或 CAPA。
6. 应急事件记录启动、指挥关系、过程日志、审阅和结案。
7. 事故险情记录快报、调查、损失、原因、责任、措施和结案。
8. 防台覆盖预警、会议、检查、部署、动态、解除和小结。
9. 人工向外部上报时只记录渠道、时间、经办人、状态和回执。

硬性验收：
- 计划、实施和评价可双向追踪。
- 事故未完成调查和措施不能结案。
- 防台各阶段按船舶聚合并有时间线。
- 人工上报不得显示“接口已同步”。
- 所有发现可进入统一 CAPA。

验证：
- 运行完整测试、API/Web build、OpenAPI、migration 和文档校验。

最终报告：
- 提供一条演习评价转 CAPA、一条事故调查结案和一条防台全过程证据。
```
