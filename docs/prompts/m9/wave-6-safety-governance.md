# M9 Wave 6 提示词：安全责任、费用与管理复查

```text
执行 M9 Wave 6，建设安全责任制、安全费用、指定人员监督、船长复查和管理评审。

前置：Wave 5 通过。

必须阅读：
- AGENTS.md
- docs/requirements/M9-专业安全业务深化与体系完善.md
- docs/plans/M9-execplans.md
- docs/plans/M9-wave-backlog.md
- safety-governance 规格组
- M8 计划任务、检查、证据和 CAPA 规格
- 采购管理规格
- 现有企业制度、会议、年度计划和财务业务实现

按 SDD/TDD 完成：
1. 冻结责任、费用、监督、复查和管理评审规格。
2. 先写责任版本、签名身份、预算并发占用、采购释放和复查权限测试。
3. 实现安全责任模板、适用岗位、年度签订、签名和履职检查。
4. 实现安全费用年度计划、类别、预算、使用登记和统计。
5. 采购单通过来源关联占用安全费用，取消或驳回释放占用。
6. 实现指定人员周期计划、多人监督检查和问题转 CAPA。
7. 实现船长复查清单、会议、报告和岸基审阅。
8. 实现管理评审输入、决议、行动项、任务跟踪和有效性评价。

硬性验收：
- 历史责任书保留签署时版本和身份。
- 安全费用不重复记账，预算占用可追溯。
- 指定人员和船长复查问题进入统一 CAPA。
- 管理评审行动项进入统一任务并可逾期升级。
- 不建设财务总账或支付系统。

验证：
- 运行完整测试、API/Web build、OpenAPI、migration 和文档校验。

最终报告：
- 附责任签署、预算采购联动和复查问题闭环证据。
```
