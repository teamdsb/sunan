# 领域术语表

本文档定义苏南船舶管理系统中使用的领域术语，供所有团队成员统一理解。

## 船舶与人员

| 术语 | 英文标识 | 说明 |
|---|---|---|
| 船舶 | vessel | 公司旗下的所有船只，分主船（苏南012、022）和辅船（苏南辅系列） |
| 船员 | crew | 在船上作业的人员，区别于岸基管理人员 |
| 船务部 | shipping_dept | 负责船舶运营管理的内部部门 |
| 船长 | captain | 船舶最高负责人 |
| 轮机长 | chief_engineer | 负责轮机系统的船员 |
| 岸基 | shore_based | 在陆地办公室工作的管理人员 |
| 泊位 | berth | 船舶停靠的位置 |
| 航次 | voyage | 一次完整的运输行程 |
| 航线 | route | 船舶运行的固定路线 |

## 证书与证照

| 术语 | 英文标识 | 说明 |
|---|---|---|
| 电子证照 | certificate | 船舶、车辆、人员的各类资质证书电子版 |
| 国籍证书 | nationality_cert | 船舶注册国籍的证明文件 |
| 所有权证书 | ownership_cert | 证明船舶所有权的文件 |
| 船检证书 | inspection_cert | 船舶检验机构出具的安全检验证书 |
| 最低配员证 | min_crew_cert | 规定船舶最低安全配员人数的证书 |
| 电台执照 | radio_license | 船舶无线电台使用许可证 |
| 设施设备检测报告 | equipment_report | 船上设施设备定期检测出具的报告，每年一次 |
| 海图更新 | chart_update | 航海图纸的定期更新记录，主船每半年一次 |
| 年度检验 | annual_inspection | 年度定期检验，适用于船检证书和车辆 |
| 中间检验 | intermediate_inspection | 两次年度检验之间的中期检验 |

## 证书提醒

| 术语 | 英文标识 | 说明 |
|---|---|---|
| 证书提醒 | certificate_reminder | 系统在证书到期前自动发送的提醒通知 |
| 到期日 | expiry_date | 证书的有效期截止日期 |
| 提前提醒天数 | advance_days | 到期前多少天开始提醒：证书30天，合同90天 |
| 服务合同 | service_contract | 与外部机构签订的服务协议 |
| 人员合同 | personnel_contract | 公司与员工签订的劳动合同 |

## 业务操作

| 术语 | 英文标识 | 说明 |
|---|---|---|
| 污油水 | oily_water | 含有油污的废水，需专门接收处理 |
| 生活污水 | sewage | 船舶生活区产生的污水 |
| 围油栏 | oil_boom | 防止油污扩散的拦截设备及相关作业 |
| 班前会议 | pre_shift_meeting | 作业开始前的安全会议 |
| 完工确认 | completion_confirmation | 作业完成后的记录确认 |
| 巡查记录 | patrol_record | 作业过程中的定期巡查记录 |
| 隐患排查 | hazard_inspection | 安全隐患的定期检查与整改 |

## 采购与报销

| 术语 | 英文标识 | 说明 |
|---|---|---|
| 录单 | submit_order | 员工从下往上发起的采购或报销申请 |
| 提单 | issue_order | 管理人员从上往下布置的任务或检查 |
| 大额采购 | large_purchase | 总经办负责的超过一定金额的采购事项 |

## 工作流程

| 术语 | 英文标识 | 说明 |
|---|---|---|
| 审批人 | approver | 具备审批权限的管理人员 |
| 发起人 | initiator | 发起流程申请的人员 |
| 闭环 | closed_loop | 问题从发现到整改完成的完整记录链路 |
