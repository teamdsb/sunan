## 一、文档说明

本附件用于明确苏南船舶管理系统的建设范围、基础规则与模块需求。除合同正文另有约定外，本附件与主协议正文具有同等效力。

| 序号 | 板块 | 定位 | 说明 |
|---|---|---|---|
| 1 | 办事 | 统一入口 | 集中展示海事、海关、边检、船检、环保及园区等办公端口，并支持搜索。 |
| 2 | 采购管理 | 采购审批与统计 | 按 5 个部门细化采购，支持录单、审批、报表、打印、附件上传与留存。 |
| 3 | 工作平台 | 部门业务承载 | 承载总经办、财务部、业务部、船务部、后勤部及工作组模块。 |

以下正文按需求文档原始章节和模块结构展开。

## 1. 项目说明

### 1.1 项目名称

船舶公司企业微信工作台建设。

### 1.2 文档说明

本文根据《工作台.zip》中的现有目录、构思文件、模板文件和示例资料整理。

本文按原始目录进行功能对齐，保留原始模块命名。原始资料中仅有模块目录、无进一步说明的内容，在文档中按“已设置模块”表述。

### 1.3 工作台总体结构

工作台分为四个板块：

1. 办事

2. 采购管理

3. 工作平台

4. 我的

### 1.4 工作台基本规则

根据现有构思文件，工作台需满足以下基本规则：

1. 审批人需具备相应使用权限后方可使用审批功能。

2. 工作台按职务进行注册和配置。

3. 工作流支持两类模式：

- 录单：员工从下往上发起流程。

- 提单：管理人员从上往下布置任务。

4. 采购管理以“录单”方式为主。

5. 培训等任务下发类模块可采用“提单”方式。

## 2. 办事板块

### 2.1 模块说明

办事板块用于集中展示办公端口，在工作台中实现统一入口，支持随进随用，并增加搜索端口。

### 2.2 端口分类

办事板块包含以下端口分类：

1. 海事端口

2. 海关端口

3. 边检端口

4. 船检端口

5. 环保端口

6. 其他端口

7. 石化园区端口

### 2.3 功能要求

1. 支持在工作台集中展示上述端口。

2. 支持员工点击进入对应端口。

3. 支持端口搜索。

4. 海关端口、石化园区端口已有现成访问地址，可按现有资料配置。

## 3. 采购管理板块

### 3.1 模块说明

采购管理板块按部门细化采购，实现采购审批流程，并生成采购统计报表。

### 3.2 总体要求

根据现有构思文件，采购管理板块应支持：

1. 按部门细化采购。

2. 实现采购审批流程。

3. 生成月度采购数据表。

4. 生成年度采购数据表。

5. 区分部门采购清单和部门细分采购清单。

### 3.3 报销采购管理

采购管理现有主模块为“报销采购管理（能审批-能打印 A4-能上传报销单据-能下载打印）”。

该模块应支持：

1. 按 5 个部门区分采购单据。

2. 实现单据申报。

3. 实现审批管理。

4. 实现月度报表审批管理。

5. 实现年度报表审批管理。

6. 支持 A4 打印。

7. 支持上传单据和照片。

8. 支持按年度保存记录。

9. 支持 3 年内查询。

### 3.4 部门范围

采购管理按以下 5 个部门区分：

1. 总经办

2. 业务部

3. 财务部

4. 船舶部

5. 后勤部

各部门现有范围如下：

• 总经办：大额采购、业务支出。

• 业务部：业务部相关单据。

• 财务部：财务部所有开支单。

• 船舶部：所有船舶单据、船务部相关单据。

• 后勤部：办公室、仓库、宿舍、食堂、车辆及其他杂项采购录单。

### 3.5 报表要求

采购管理板块现有报表要求如下：

1. 月度采购数据表。

2. 年度采购数据表。

3. 部门采购清单。

4. 部门细分采购清单。

部门细分采购清单按部门下具体对象区分。现有资料举例为船舶部按苏南 012、苏南 022 等船舶区分。
