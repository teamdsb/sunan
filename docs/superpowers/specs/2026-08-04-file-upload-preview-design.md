# 文件上传扩展与统一预览设计

## 目标

扩展通用业务附件的可上传格式，在选择文件前明确显示格式与大小限制，并为附件、刚上传文件以及采购导出 PDF 提供不依赖企业微信 JS-SDK 的系统内预览能力。改造保留 OSS 预签名直传和业务记录授权边界，不引入 Office/WPS 在线解析服务，也不解压 ZIP/RAR。

## 已确认范围

### 格式与分类

通用业务附件新增 `TXT`、`CSV`、`HEIC`、`ZIP`、`RAR`、`WPS`、`ET`、`DPS`。适用分类包括：

- 企业资料
- 企业制度
- 采购附件
- 会议记录
- 工作台附件

这些分类继续支持现有的 `PDF`、`JPG`、`JPEG`、`PNG`、`DOC`、`DOCX`、`XLS`、`XLSX`。本期不额外增加未提出的格式。

专用分类保持现状：

- 证书文件：`PDF`、`JPG`、`JPEG`、`PNG`，最大 `20MB`
- 检查照片：`JPG`、`JPEG`、`PNG`，最大 `10MB`

### 大小限制

- 企业制度：单个文件最大 `50MB`
- 企业资料、采购附件、会议记录、工作台附件：单个文件最大 `20MB`
- 不为 ZIP/RAR 设置单独的更高上限

### 在线预览能力

系统内直接预览：

- `PDF`
- `JPG`、`JPEG`、`PNG`
- `HEIC`，在浏览器端按需转换为可显示图片
- `TXT`
- `CSV`

仅展示文件信息并提供下载：

- `DOC`、`DOCX`、`XLS`、`XLSX`
- `WPS`、`ET`、`DPS`
- `ZIP`、`RAR`

## 根因

1. 后端 `FILE_CATEGORY_RULES` 只接受现有扩展名与一组固定 MIME；浏览器对 WPS、HEIC、ZIP、RAR 等文件可能上报空 MIME 或 `application/octet-stream`，导致扩展名合法但仍被拒绝。
2. `FileUploadField` 没有 `accept`、格式/大小说明或选择后本地校验，用户只能在请求失败后得知限制。
3. 通用 `previewFile` 在 `window.wx` 不存在时直接抛错，没有浏览器预览路径，也没有把失败反馈显示给用户。
4. 已绑定附件缺少跨模块统一预览组件；采购附件虽然有业务授权下载地址，但浏览器环境只会打开新标签页。
5. 采购 PDF 在异步生成完成后调用 `window.open`，可能失去浏览器的用户激活状态并被拦截。

## 架构

### 后端文件策略

`FILE_CATEGORY_RULES` 仍是格式和大小限制的单一权威来源，并扩展为能描述：

- 分类允许的扩展名
- 每个扩展名对应的规范 MIME
- 可接受的兼容 MIME
- 最大文件大小
- 存储前缀

新增受认证的文件策略查询接口。前端按分类读取 `allowedExtensions`、`maxSize` 和用于文件选择器的 `accept` 值，不再手工复制限制列表。

上传校验以规范化扩展名为第一入口：

- 扩展名必须属于当前分类。
- 浏览器 MIME 与该扩展名明确兼容时接受。
- MIME 为空或为 `application/octet-stream` 时，仅对已允许扩展名回落到后端定义的规范 MIME。
- 浏览器提供了明确但与扩展名冲突的 MIME 时拒绝，不能用改后缀绕过校验。
- 预签名响应返回最终规范 MIME；OSS PUT 和 callback 都使用该值，保证对象头、数据库元数据和预览判断一致。

### 授权与文件来源

预览组件只接收已经过授权的临时文件来源，不自行用全局 `ossKey` 获取任意对象。

- 刚上传且尚未绑定的文件可使用 callback 返回的短期地址。
- 已绑定附件通过证照、企业资料、企业制度、采购或工作台所属业务记录的授权接口签发地址。
- 每次预览或下载时重新获取地址，不缓存过期签名。
- 无权访问业务记录时不返回文件地址或文件内容。

### 前端组件

#### `FileUploadField`

职责：

- 加载并展示当前分类的允许格式与大小限制。
- 为原生文件选择器设置 `accept`。
- 选择文件后在预签名前校验扩展名和大小。
- 显示上传进度、失败原因与重试入口。
- 上传成功后把 `FileRecord` 交给业务页面绑定。

限制提示位于上传按钮之前，格式采用易读名称，大小采用 MB。策略加载失败时禁用上传并提供重试，不能在限制未知时盲目放行。

#### `FilePreviewModal`

统一接收文件名、文件大小、规范 MIME、扩展名，以及按需获取临时地址的函数。预览弹窗始终提供关闭和下载入口。

- PDF：在弹窗内容区使用浏览器 PDF 容器显示；加载失败时降级为下载。
- JPG/JPEG/PNG：以等比缩放图片显示，支持长图滚动。
- HEIC：动态加载浏览器转换模块，将文件转换为 JPEG 对象 URL；关闭弹窗时释放对象 URL。转换失败时降级为下载。
- TXT：以纯文本方式转义渲染，不执行 HTML；优先 UTF-8，失败时回落到 GB18030。
- CSV：按文本读取并解析为只读表格，不执行公式、链接或脚本。
- Office、WPS 和压缩包：显示格式、大小和“不支持在线预览，请下载后查看”。

为避免大文件拖慢 H5 页面，TXT/CSV 只读取前 `2MB`。内容被截断时显示明确提示；CSV 最多展示前 `500` 行、`50` 列。

### 业务页面接入

- 证照、企业资料、企业制度、采购和工作台的已绑定附件列表增加统一“预览”和“下载”操作。
- 企业微信 JS-SDK 可用时可以作为增强能力，但不是预览成功的前置条件。
- 不支持在线解析的格式仍打开同一预览弹窗的信息态，避免按钮点击无反馈。

## 采购 PDF

采购单详情和报表审批单详情保留“导出 PDF”，并新增独立“预览 PDF”。

- “预览 PDF”：调用现有后端生成接口，成功后把返回的临时地址交给 `FilePreviewModal`，不调用异步 `window.open`。
- “导出 PDF”：调用生成接口后走统一下载帮助函数，下载生成文件。
- 两个动作分别显示生成中状态，并防止重复提交。
- 生成失败时保留当前页面并显示可重试错误，不打开空白页。

## 错误处理

- 文件格式不允许：上传前显示文件名、实际扩展名和当前允许格式，不请求预签名。
- 文件超限：显示实际大小和最大大小，不请求预签名。
- 策略加载失败：禁用上传，显示重新加载入口。
- OSS 直传或 callback 失败：保留已选择文件并提供重试。
- 签名地址失效：重新获取一次业务授权地址；仍失败则显示错误与下载重试。
- PDF、图片、HEIC、TXT、CSV 解析失败：保留文件信息和下载入口。
- 不支持预览的格式：使用明确的信息态，不把它作为系统错误。
- 预览弹窗关闭时取消未完成的内容读取并释放 Blob URL。

## 安全与性能

- 文件扩展名和客户端 MIME 都是不可信输入；后端继续做分类、大小和兼容关系校验。
- 文本和 CSV 只以转义后的只读内容呈现，不注入 HTML，不执行 CSV 公式。
- ZIP/RAR 不在服务端或浏览器内解压。
- HEIC 转换模块按需加载，不能进入普通首页初始包。
- 预览内容读取有 `2MB` 上限，图片和 PDF 使用滚动容器，避免撑破移动端视口。
- 所有已绑定附件继续走业务记录权限；不扩大当前角色或数据范围。

## 测试设计

### 后端

- 每个新增扩展名在允许分类中可以预签名并注册 callback。
- 专用证书和检查照片分类继续拒绝新增通用格式。
- 空 MIME 与 `application/octet-stream` 对允许扩展名规范化成功。
- 明确冲突 MIME、未知扩展名和超过大小边界时拒绝。
- 文件策略接口与后端实际校验规则一致。
- 各业务附件地址接口覆盖有权、无权、记录不存在和文件未绑定。

### 前端

- 限制文案在上传按钮前显示，文件选择器 `accept` 与策略一致。
- 非法格式和超限文件不会调用预签名接口。
- 上传成功、失败重试和 callback 规范 MIME 正确。
- PDF、图片、TXT、CSV 和 HEIC 分别进入对应预览器。
- 文本截断、CSV 行列上限、HEIC 转换失败和通用加载失败都有降级状态。
- Office、WPS、ZIP、RAR 显示文件信息和下载按钮。
- 没有 `window.wx` 时预览仍然可用。
- 采购“预览 PDF”不调用 `window.open`；“导出 PDF”调用下载流程。

### 验收

- 运行文件模块、相关业务模块和采购 PDF 的定向测试。
- 运行完整 Web 与 API 测试及生产构建。
- 在桌面与移动视口验证限制提示、弹窗滚动、图片缩放、文本/CSV 截断和不支持格式降级。
- 在普通浏览器和企业微信兼容环境验证同一套预览入口。

## 非目标

- 不接入第三方 Office/WPS 在线预览服务。
- 不解析、解压或展示 ZIP/RAR 内部目录。
- 不把 Office/WPS 文件转换为 PDF。
- 不改变现有 OSS 供应商、存储目录或业务审批流程。
- 不在本期引入异步转码队列、病毒扫描平台或长期公开下载链接。
