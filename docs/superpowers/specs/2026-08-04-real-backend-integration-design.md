# 前端真实后端接入设计

## 目标

`Fix-ding` 前端以 `origin/main` 后端为唯一业务数据源。浏览器运行时、本地预览和生产构建均不得使用前端业务 mock；测试可保留 `vi.mock` 等仅存在于测试进程的隔离替身。

完成后需要同时交付：

- 所有页面业务数据来自真实 API，或在后端无能力时显示明确的中性空态。
- 删除运行时 mock、mock 启动入口、业务 fixtures 和假用户认证路径。
- 一份前后端接口覆盖矩阵，列出已对接、后端缺失和后端存在但前端未使用的接口。
- 通过类型检查、相关页面测试、生产构建、生产包 mock 扫描和真实 API 联调验证。

## 范围

### 删除的运行时能力

- `VITE_MOCK_MODE` 及其环境类型和条件分支。
- `apps/web/src/mocks` 运行时目录及依赖它的测试。
- `dev:web:mock` 脚本和 `.env.mock.local`。
- `bootstrapMockAuth`、本地假用户、`local-preview-token` 和 `VITE_LOCAL_BYPASS_AUTH`。
- 文件上传、企业微信 JS-SDK、路由守卫和应用壳层中的 mock 特判。

普通单元测试中的模块级 `vi.mock` 不属于运行时 mock，继续保留。

### 页面数据改造

#### 我的

- 企业资料、企业制度、证照、提醒、船舶监控和工作台指标分别使用现有领域 API。
- 删除固定的“资料完善度 85%”“制度文档 12 份”。制度数量来自列表元数据或列表长度；资料完整度仅在后端能提供足够字段时计算，否则使用资料条目数或中性描述。
- API 请求失败必须显示错误状态，不得降级成业务数字 `0`。

#### 办事

- 分类、入口、打开入口和治理台继续使用 `/office/*`。
- 删除固定办理数量 `1/2/8`。
- 主分支后端没有“我的办理实例/状态统计”能力时，页面不得模拟数据；该区域显示“暂未提供办理统计”，并在接口矩阵中登记后端缺口。

#### 采购

- 预算指标使用 `/procurement/budgets/summary`。
- 待审批数量和清单使用 `/procurement/approvals/pending`，不再从订单第一页推算。
- 订单清单使用 `/procurement/orders`，超预算状态按预算作用域和后端字段判断，不再按标题关键字判断。
- 删除“张三/李四”等固定人员姓名；后端未提供展示名时显示已有账号标识或隐藏申请人字段。

#### 工作台

- 指标使用 `/workbench/dashboard`，模块使用 `/workbench/modules`，记录使用 `/workbench/records`。
- 首页模块和记录按后端返回数据及状态排序，不依赖 mock 专用模块编码。
- 活跃模块数、当前页记录数和最近记录均由响应数据计算；缺失或请求失败时显示加载、空态或错误态。

## 数据流与认证

应用启动后只执行真实认证流程：恢复本地 JWT；无 JWT 时跳转企业微信 OAuth；接口收到 401 时尝试 `/auth/refresh`，失败后清理会话并重新授权。`baseApi` 始终通过 Axios 请求 `VITE_API_BASE_URL`，所有成功响应遵守 `{ data, meta? }` 契约。

生产和本地联调均需要配置真实 API 地址、企业微信 Corp ID、Agent ID 和回调地址。生产 compose 必须显式传入这些值，不再传入 mock 或本地绕过开关。

## 接口覆盖矩阵

新增 `docs/audits/frontend-backend-api-coverage.md`，以 HTTP 方法和规范化路径为主键，分为：

1. 前端已调用且后端已实现。
2. 前端需要但后端缺失。
3. 后端已实现但前端没有调用。
4. 企业微信回调、后台任务等不应由 H5 主动调用的后端接口。

矩阵必须区分“未使用”和“无需前端使用”，避免把服务端回调、健康检查或后台任务误报为前端缺失。

## 错误与空状态

- 加载中显示骨架或现有加载提示。
- 空数据使用业务语义空态，不填充示例记录。
- 401 进入认证恢复；403 显示权限不足；其他错误显示可重试错误态。
- 聚合首页不能把请求失败折算成 `0`。只有成功响应中的真实零值才能显示 `0`。

## 验收标准

- 源码中不存在运行时 `VITE_MOCK_MODE`、`bootstrapMockAuth`、`local-preview-token` 或对 `apps/web/src/mocks` 的生产引用。
- `package.json` 不再提供 mock 启动脚本，仓库不再包含 `.env.mock.local`。
- 设计稿中的固定业务数字、固定人员姓名和标题关键字业务判断已移除。
- 接口覆盖矩阵中的每个前端 API 都能映射到 `origin/main` 控制器，无法映射的条目明确标记为后端缺口。
- 生产构建产物不包含 mock handler、mock fixture 或假认证字符串。
- 受影响页面测试、路由/鉴权测试、TypeScript 构建和 Vite 生产构建通过。
- 使用真实后端完成认证、四个模块首页加载和至少一个详情页请求的联调记录。

## 非目标

- 本次不新增后端数据库表或业务流程。
- 本次不为仅后端使用的回调、定时任务和运维接口创建无意义前端页面。
- 本次不改变已确认的移动端视觉设计，仅替换数据来源和错误状态。
