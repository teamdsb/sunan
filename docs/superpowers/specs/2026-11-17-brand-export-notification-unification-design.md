# 苏南船舶管理品牌与输出统一设计

## 目标

统一导航栏、服务端 PDF/XLSX 导出和企业微信真实通知的视觉识别，使不同模块的输出一眼属于同一套“苏南船舶管理”系统。业务字段、统计口径、状态含义、通知收件人、去重键、链接和投递状态保持原样。

## 已确认方向

采用 A「深海企业」方向：

- 主色：深海蓝，作为导航栏、PDF/XLSX 表头和通知强调色。
- 辅色：青绿色，只用于导航操作、链接和状态强调，不改变业务状态文本。
- 背景：输出文件以白底为主，内容区使用很浅的蓝灰色分隔；企业微信卡片保持纯文本卡片接口，不新增图片消息依赖。
- 字体：沿用现有中文字体链路；Web 使用现有中文字体栈，PDF 继续通过 `createChinesePdfFont` 嵌入可用中文字体，XLSX 统一使用微软雅黑字体名。
- Logo：仅在 Web 桌面/移动导航中显示，位于“苏南船舶管理”文字旁。PDF、XLSX、企业微信通知不显示 Logo 图片，避免改变文档正文和消息有效载荷。

## 统一规则

### 导航栏

在 `AppShell` 的桌面和移动品牌区域复用同一 Logo 资源；图片使用固定方形容器和 `object-fit: cover`，不改变现有导航文字、模块入口、用户区、重新认证和响应式行为。资源进入 Web 可访问的静态资产目录，保留原始 PNG，不在运行时请求后端。

### PDF

增加共享 PDF 视觉主题参数/辅助函数，供当前业务 PDF 生成器复用：

- A4/A3 纸张和横竖方向仍由业务输入决定。
- 统一左右边距、页眉标题层级、元信息行、分节标题、表头填充色、正文行高、斑马纹、警示色、页脚分页和上海时间生成时间。
- 统一表头文字、线条和警示色；只替换排版和颜色，不改列、字段、排序、数值、图片和状态文案。
- 覆盖工作台业务报表、采购报表、船舶自查整改记录、工作台打印快照以及现有采购单 PDF。旧 PDF 中表达业务内容的标题、字段和附件仍保留。
- 受控副本、来源、权限范围和生成时间继续保留；不可把 Logo 或视觉装饰写入用户未要求的业务字段。

### XLSX

扩展现有 `workbook` 共享生成器作为唯一主题入口：

- 统一工作簿作者、标题元数据、默认中文字体、标题行、范围/生成时间行、说明行、表头、边框、行高、冻结窗格、打印方向、纸张、边距、页脚和分页。
- 表头统一深海蓝白字，内容使用白色/浅蓝灰斑马纹，警示值使用浅金色底和深金色字。
- 各业务工作表继续保留原工作表名称、字段、列顺序、列宽意图、过滤条件和快照说明；只把局部样式收敛到共享主题。
- 导出仍使用现有权限范围和持久化快照，不在导出层重新查询或扩展数据范围。

### 企业微信通知

保留现有 `textcard` 消息类型、真实通知应用解析、加密配置、去重、重试、人工核对和投递审计。增加共享通知呈现器，将业务消息映射为统一结构：

- 标题：`[模块] · 事件` 的短标题，保留原业务对象和动作含义。
- 描述：首行给出对象/编号或提醒事项，第二行给出状态、时间或下一步；继续使用现有 HTML 片段能力和长度限制。
- 按钮：默认“查看详情”，业务自定义按钮只在现有语义需要时保留。
- URL、收件人、dedupeKey、sourceType、sourceId、payloadSnapshot 和投递状态不改变。
- 配置测试消息也通过同一呈现器，但允许保留管理员输入的测试标题/描述；不覆盖真实业务消息内容。
- 不在通知正文中复制 Secret、Token、内部存储键或无关调试信息。

## 兼容和范围

- 不新增数据库迁移，不改变 API 路由和响应字段。
- 不改变业务数据、导出字段、通知发送规则、收件人范围或去重规则。
- 旧文件仍可下载；新生成文件使用统一样式。历史通知的数据库快照不回写，重试使用原快照内容，只通过呈现器保证新发送内容格式一致。
- Logo 文件只被前端导航引用；服务端导出和通知服务不依赖浏览器静态资源。

## 实施边界

1. 新增共享品牌 token/资源入口和导航 Logo 组件样式。
2. 把 PDF/XLSX 的颜色、字体、间距、页眉页脚和表头样式提取到共享主题，逐个迁移现有生成器。
3. 把通知标题/描述/按钮格式提取到共享呈现器，迁移证照提醒、采购和计划任务通知以及设置页定向测试的默认展示。
4. 保留针对关键生成器的字节/文本断言、XLSX 样式断言、通知请求 payload 断言和 Web 导航渲染测试。
5. 运行 API lint、相关单元/集成测试、Web 测试、API/Web build、OpenAPI 校验、文档 inventory/index 和 `git diff --check`。

## 验收标准

- 桌面和移动导航均显示同一 PNG Logo，Logo 不出现在 PDF、XLSX 或企业微信通知正文。
- 至少一份工作台 PDF、一份采购 PDF、一份工作台 XLSX 和一份采购 XLSX 的页眉/表头/边距/字体/页脚可复核一致；业务内容逐项不变。
- 证照、采购、任务三类真实通知使用统一标题、描述和按钮结构；通知应用来源、去重、重试和审计字段保持原值。
- 现有自动化测试和构建全部通过；真实企业微信送达、真机三端和生产部署仍单独记录，不以本地替身测试代替。
