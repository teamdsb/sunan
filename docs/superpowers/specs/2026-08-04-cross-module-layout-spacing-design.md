# 跨模块页面边距与控件间距修复设计

## 目标

修复“我的首页、办事中心、采购审批页、工作台”已暴露的卡片贴合、空预警占位、顶部内容贴导航、搜索框与按钮错位、相邻控件无间距以及桌面内容宽度不一致问题。改造继续沿用蓝白企业工作台视觉，不改变业务接口、路由或权限边界。

## 已确认视觉基线

- 桌面端主内容区最大宽度统一为 `1500px`，在可用空间内水平居中。
- 桌面端左右内边距统一为 `24px`。
- 移动端使用 `18px` 至 `26px` 的安全留白，并在窄屏下避免横向滚动。
- 页面标题区与顶部导航之间保留 `20px` 至 `24px` 垂直间距。
- 同级页面区块间距统一为 `16px`；工具栏和紧密相关控件间距统一为 `12px`。

## 根因与修复策略

### 我的首页

当前状态卡独立于带 `gap` 的首页仪表盘容器，因此状态卡与后续“当前重点”面板没有稳定间距。证照预警行和预警面板也会在真实数量为 `0` 时继续渲染。

修复规则：

- 为状态卡与仪表盘建立明确的 `16px` 区块间距。
- 仅在提醒看板成功返回且 `warningTotal > 0` 时渲染“当前重点”中的证照预警项。
- 仅在实际预警明细非空时渲染证照预警面板。
- 请求失败继续使用现有错误提示，不把加载失败或缺失数据当成 `0`。

### 办事中心

办事首页容器顶部内边距为 `0`，导致标题紧贴桌面顶栏。搜索框由独立 `Input` 和 `Button` 拼接，而全局规则同时给输入外壳和内部 `.ant-input` 设置最小高度，造成组合控件尺寸与边框错位。

修复规则：

- 首页容器增加与其他模块一致的顶部留白。
- 搜索改为一体化 Ant Design 搜索控件，输入区与搜索按钮共用组合边框。
- 组合控件外壳高度统一为 `46px`；内部输入不重复设置最小高度。
- 分类按钮保持响应式换行，横向与纵向间距均保持清晰，不允许边框贴合。
- 保留现有 URL 查询参数、回车搜索和点击搜索行为。

### 采购审批页

“返回采购首页”按钮与部门筛选位于两个连续块级元素中，页面骨架没有为这两个操作定义间距，窄屏下会直接贴合。

修复规则：

- 采购审批与报表审批页使用统一工具栏承载返回按钮和部门筛选。
- 桌面端按内容宽度横排，移动端改为单列。
- 两个控件之间始终保留 `12px` 间距，控件高度统一为 `46px`。
- 保留现有导航、筛选状态与审批数据流。

### 工作台与跨模块内容宽度

模块首页和通用子页同时存在 `1180px` 与 `1500px` 两套最大宽度，导致同一桌面壳层下左右边距明显跳变。

修复规则：

- 我的、办事、采购、工作台模块首页和通用页面骨架共享 `1500px` 内容宽度基线。
- 内容区始终水平居中，左右留白对称。
- 不改变侧边导航宽度、折叠行为、顶部栏和移动端底部导航。

## 交互状态

- 搜索按钮、返回按钮、分类按钮和筛选控件保留 hover、键盘焦点、按下及禁用状态。
- 键盘焦点使用可见但不过度扩张的企业蓝轮廓。
- 交互状态不能改变控件几何尺寸，避免聚焦或按下时造成页面跳动。
- `prefers-reduced-motion` 下继续关闭非必要位移动画。

## 数据与错误处理

- 证照预警显示条件来自提醒看板和提醒列表真实响应，不新增本地持久化状态。
- 接口加载中时不先渲染空预警面板。
- 接口失败时保留“部分首页数据加载失败”提示，其他已成功区块继续展示。
- 办事搜索和采购筛选继续使用现有页面状态与查询参数，不修改 API 请求结构。

## 实施边界

- 允许修改 `apps/web/src/features/ui/MyHomePage.tsx`、`apps/web/src/features/office/OfficeHomePage.tsx`、采购审批相关页面、`apps/web/src/app/app.css` 及对应测试。
- 优先沿用现有 class 和组件边界；共享模式使用明确的页面容器或工具栏 class。
- 不新增第三方依赖，不修改后端，不改变产品文案范围，不恢复已删除的办事占位功能。
- 不处理与本轮截图和统一布局规则无关的业务重构。

## 验收标准

1. 我的首页状态卡与后续面板之间存在稳定间距，同级卡片不再边框贴合。
2. 证照预警为 `0` 时，当前重点中的预警项和独立预警面板均不显示；大于 `0` 时正常显示。
3. 办事中心标题不再贴顶；搜索输入与按钮同高、边框连续、圆角正确，回车和点击均可搜索。
4. 分类按钮横纵方向均有清晰间距，不出现重叠或贴合。
5. 采购审批和报表审批页的返回按钮与部门筛选之间至少保留 `12px` 间距。
6. 我的、办事、采购、工作台在桌面端使用相同的 `1500px` 最大内容宽度和对称边距。
7. `320px`、`390px`、`768px`、`1440px`、`1920px` 视口下无页面级横向滚动、控件重叠或文字溢出。
8. 受影响页面测试、完整 Web 测试和生产构建通过。

## 验证计划

- 为我的首页补充零预警隐藏和非零预警显示测试。
- 保留并扩展办事首页搜索输入、回车、点击与查询参数测试。
- 检查采购审批与报表审批页返回和筛选交互测试。
- 运行受影响测试后，再运行完整 Web 测试与生产构建。
- 使用真实浏览器在五档视口检查页面边距、卡片间距、搜索组合控件、工具栏以及横向滚动。
